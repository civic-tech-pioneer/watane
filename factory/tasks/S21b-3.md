## Goal
app build stage C (`app/TECHNICAL.md` 12): the app opens `watane_dist::Dist` on the same home
beside the host, answers dist's signature requests through `DistConfirm` (the consent view's `Sign`
request), and offers the stage C commands of 7 and the route `POST /api/publish` of 8.1. Alice sets
her name, publishes a packed mod from a local program, sets her site URL and copies her link; Bob
enters the link and, after one consent view that shows Alice's profile name, her fingerprint and
"signature verified", the mod runs in his app. A tampered package is refused with a cause that
names the hash mismatch, and nothing is installed. The main page shows identity, site, channels and
an "Install from link" field.

## Interface
Takes from S21b-1 (host), fixed: `watane_host::Source::Release { package: watane_pkg::Package,
entry: watane_log::Entry }`; re-exports `watane_host::{watane_log, watane_pkg}`;
`HostError::Verify { check, reason }` (code `verify`); `PlanEntry.publisher`/`release` and
`InstalledMod.release` filled for a release. S21b-1 is in your branch before you start;
build on it as is.
Takes from dist, as in `dist/TECHNICAL.md` 3: `Dist::open(home, Arc<dyn Confirm>, Options)`,
`Fetched { package, entry, .. }`, `Published`, `Link: FromStr`, `DistError` (S21b-2 adds variants
`NotOwnLink` and `HeadMismatch`; map dist errors generically, never by variant list).
Dependency: `watane-dist = { path = "../dist" }`; dev `tower-http` (static files).
