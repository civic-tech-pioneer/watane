## Goal
Alice manages her mods in the main window and every screen tells her what happened, in her terms.
After this task: a page whose provider is disabled shows the host's own reason; following a
channel or adding an index shows a busy button while it works (they can hang for 30 s); channel
rows read like the rest of the manager, not raw transport text (no base URL, no `ok`/`failed`
tokens); installing a mod that made watane follow a channel says so in the installed note; the
library is refreshed in a hidden or occluded window too (slower).
(Dropped by the product owner: a focus guard on the confirm panel. The S88 native-blur race is an
accepted limit; do not build it.)

## Interface
Takes from S90-2 (built in parallel; do not wait for it): the JSON result of the Tauri commands
`install_release` and `install_link` gains `"followed": [<string>]`, each string the party label
of a channel this command started following (empty array when none). Other install commands
never carry it. Read it as `result?.followed || []`.
