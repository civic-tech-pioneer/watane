## Goal
host stage 5 for a participant home. The app can plan a set of folders, show the plan, and
install it after the participant's answer through a `Confirm` it hands to `Host::open`. A home
keeps each mod's grants: the app can withdraw and give back any declared grant, and a withdrawn
grant stops at once (a call import, a subscription, storage). The app can disable, enable and
remove a mod, keep or delete its data, and list and remove toolsets and tokens. The app adds its
own routes to the local API through `serve(port, extra_api)`. Preview homes behave as today.

pub enum Mode { Home { app: Option<Arc<dyn Confirm>> }, Preview }   // Debug by hand
pub trait Confirm: Send + Sync + 'static {
    fn install(&self, request: InstallRequest) -> Pin<Box<dyn Future<Output = Answer> + Send>>;

pub struct InstallRequest { pub entries: Vec<PlanEntry>, pub requester: Requester }

pub struct Plan;  // entries(), missing(), needs_confirmation(); Serialize; Drop cleans staging
pub struct PlanEntry { .. as 2.4 .. }   pub enum Change { New, Update { from_version }, Unchanged }

impl Host {
    pub fn plan(&self, sources: Vec<Source>) -> Result<Plan, HostError>;
    pub async fn install(&self, plan: Plan, requester: Requester) -> Result<Vec<InstalledMod>, HostError>;
    pub fn mods(&self) -> Vec<InstalledMod>;        // sorted by local name; `page` set once served

    pub fn tokens(&self) -> Vec<TokenInfo>;         // TokenInfo { id: TokenId, toolset, handle }, Serialize

}
