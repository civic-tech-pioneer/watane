## Goal
Two of the human's answers (host 18, Q30 b and Q32 b). (1) When Desk asks to install a release with a
link of a channel Alice's home does not read, Alice first sees "Desk asks to read <link>". Deny: nothing
is fetched, the request reads `denied`. Approve: the app reads the link, then shows the install's own
consent as for any manager install; after the install the channel is followed. (2) Every consent that
a manager started offers "Deny and stop asks from Desk": it denies and withdraws Desk's `manage` grant,
so Desk's next ask traps `not_granted` until Alice gives the grant back.
