## Goal
Two local API changes that agents use (dev 9). `POST /api/fetch` hands a local program a
verified package by link or by release, and follows, installs, grants and signs nothing.
`POST /api/publish` takes the `Watane-Provider-Links` header and, after the release is signed,
lists each provider of another publisher in the own index (each with its own `list` consent),
and reports `providers: [{provider, listed}]`.
