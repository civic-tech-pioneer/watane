## Goal

Paths in dev's answers read the same everywhere, so an agent can copy `dir` and
`next` and compare them; a mod started with `new --from` is the new mod's own
(its name, no publisher build); the fake host never dies on a bad fixture; text
mode is readable for argument errors. Outcomes 3, 4 (`new --from` part) and 5 of S39.

## Acceptance

AC1 `dir` and every path in `next` are canonical (on macOS `/tmp/x` reads
`/private/tmp/x`) for every command, also when the home is the default one (no
`--home`, `WATANE_HOME`/`watane_host::default_home`) and in publish's
`version_exists` / `host.no_answer` rerun `next` (`--dir` and `--home`). Test:
run `install`/`publish` with a fake home under a symlinked dir (or `/tmp` on
macOS) and assert `dir`, and the `--dir`/`--home` in `next`, equal the canonical
paths; one test with the default home (set `HOME` to a temp dir).
AC2 `--home x/../h` where `x` does not exist: `env.host_not_running`, exit 3,
message `no watane app runs for the home x/../h (x does not exist)` style: the
message names the given path as written; never `internal` "No such file".
AC3 `new [<slug>] --from <link>`: `mod.toml` `name` is the template's name for the
folder's slug (as `new <slug>` writes it), not the origin's; a `logic.wasm` in the
package is not written (and not in `result.files`). With no `<slug>`, the same
rule (the release's slug). Extend `tests/build_on.rs` AC1 (the `ratings` fixture
holds a `logic.wasm`).
AC4 `fake-watane --help` and `-h` print the usage and exit 0 (pin it with a test if
it already holds). A `fake.json` `"fetch"` entry whose `package` file is missing
or unreadable answers 409 `fetch_refused` with a message naming the file; the
fake keeps serving the next request. Document in 15.3.
AC5 Text mode (2.3): an argument error prints `error[usage.args]: <clap text>`,
its fix, and `<command or watane-dev>: failed`; never a line that is only
`: failed` (an empty command name). Test for an unknown subcommand, a missing
argument and no arguments at all (pin it if it already holds).
AC6 TECHNICAL 2.3, 3, 9.6/9.7, 10.2, 15.2 and 15.3 say the above.
