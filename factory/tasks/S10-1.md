## Goal
The `app/` crate exists as a member of the root workspace, with the two pieces of the app that
need no window: the consent `Broker` (the queue that every confirmation of the app goes through,
one request at a time, first in first out, a no after 600 s) with its view model `Request`, and
the consent mark (two words of a home that no mod can know). No Tauri yet: task S10-3 adds the
windows on top of this crate.

## Acceptance
- AC1 `cargo test -p watane-app` runs `consent::tests` and `mark::tests` and they pass; the root
  `Cargo.toml` lists `app` as a member; `Cargo.lock` is committed.
- AC2 (FIFO, APP-F-17) Three `ask`s queued in order A, B, C: `current()` is A; answering A makes
  `current()` B; the listener is called with the new head after each change (`Some(id)`, and
  `None` when the queue empties).
- AC3 `answer` with the id of B while A is the head -> `ConsentError::Stale`; an unknown id ->
  `Stale`; answering the same id twice -> `Stale` the second time.
- AC4 `Approve { withheld }` naming a `(local, key)` that is no grant line of the request ->
  `UnknownGrant`; any non-empty `withheld` on a `Sign` request -> `UnknownGrant`; the request
  stays open after either error.
- AC5 Dropping an `ask` future before its answer removes its request (the next one becomes the
  head and the listener hears it).
- AC6 `deny_all` answers `Deny` to every open request; `ask_blocking` from a plain thread gets
  the answer given from another thread.
- AC7 (W19, APP-F-18) With tokio paused time, a request with no answer is answered `Deny` and
  removed 600 s after it was queued (not at 599 s).
- AC8 `AskId` is 32 lowercase hex characters, from 16 random bytes; two ids differ.
- AC9 `Request` and `Answer` serialize as the JSON of TECHNICAL 6.1 and 6.2 (the install example
  of 6.2 round-trips; `Answer::Deny` is `{"answer":"deny"}`).
- AC10 `mark::read_or_create(home)`: on a home without `app/mark` it creates `<home>/app/` and
  the file, mode 0600, matching `^[a-z]+ [a-z]+\n$` with both words in `WORDS`, and returns the
  two words without the newline; a second call returns the same words; a file with bad content
  (empty, one word, a word not in `WORDS`, no trailing newline) is replaced by a valid one;
  `WORDS` has 64 distinct entries.
- AC11 `cargo clippy -p watane-app --all-targets -- -D warnings` and `cargo fmt --check` pass.

## Interface

`watane_app::consent::{Broker, AskId, Answer, Withheld, ConsentError, Request, PlanMod, Party,

answer, deny_all, set_listener}`; `watane_app::mark::{WORDS, read_or_create}`.
`AskId` also gets `pub fn as_str(&self) -> &str` and `impl FromStr` (any string; an id that is
not queued is `Stale` at `answer`), so a Tauri command can take it as an argument.
