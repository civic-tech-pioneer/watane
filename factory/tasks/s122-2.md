## Goal
Alice can set, replace and remove a key from the installed provider's manager details. The app stores it by exact identity, reports only its status and origin, and cleans up on uninstall and startup.

## Acceptance
1. AC1. An eligible installed mod exposes the Judge key section with an empty origin input, canonical origin feedback, reachable hosts and an obscured key. Ineligible mods have no section. Only the main window can invoke judge commands.
2. AC2. Save and replace validate the origin and key and atomically persist the canonical origin and trimmed key by exact identity, with 0600 file and 0700 directory on Unix. Responses, views, logs and error text contain no key. Invalid or mismatched entries are refused.
3. AC3. Remove and uninstall delete the key and notify the host. With a live scripted judge stream, remove ends it gone.
4. AC4. App startup removes files for absent identities and preserves installed identities' keys.

## Spec
App TECHNICAL 5.3.4, 6.3, 14, 16 Q13, 19.4–19.6 and 19.8; FUNCTIONAL APP-F-86. W39 in spec/TECHNICAL section 6.

## Interface
Consume `watane_host::judge_origin(text: &str) -> Result<String, HostError>`, implement `AccountSource::judge(&self, provider: &str) -> Result<JudgeAccount, AccountError>` for `JudgeAccount { key: String, origin: String }`, and notify with `Host::account_changed(&self, &Account::Judge { provider: String })`. Use the existing host identity and grant APIs. No WIT change.
