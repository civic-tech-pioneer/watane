## Goal
When Alice installs a shell mod and mods that add commands to it, the plan tells her, for each
command mod, that it will "Receive the {interface} events of {provider} and answer its requests".
Journey J9 (spec/FUNCTIONAL.md "J9: Extend a shell") runs in the real app through the test driver:
the shell shows both commands without learning who gave which, a click reaches the command mods,
a failing command mod is left out, a withdrawn grant removes its command at the next collect, and a
command mod that also calls the shell is refused at the plan, which names the cycle. App stage H
(app/TECHNICAL.md 12, row H). Host already does the collect (host stage 10, S65); the app only
words the grant and proves the journey.
