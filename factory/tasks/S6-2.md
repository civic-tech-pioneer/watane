## Goal
J1 runs end to end as one test on the real programs: a reading-list mod is made with `new`,
written by the test, fails a contract test, is fixed, served; Alice adds a book on the page;
a page change is served again with her book still there; the agent reads the list through
MCP; `serve --stop` ends it. And a `serve` refused because tests fail tells the agent when a
running preview still serves the previous build, so nobody mistakes the old page for the new.
