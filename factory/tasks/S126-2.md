## Goal

A participant can see which permission prevents replacement of a saved judge key and understand exactly how to enter a matching origin. The committed fixtures still prove restart persistence in the default suite.

## Acceptance

1. AC1. Drop and reopen the fixture host once. The stored book and prior subscription result both remain available.
2. AC2. An invalid judge origin explains the forbidden username, trailing dot, path, query and fragment. A valid origin is shown canonically.
3. AC3. An origin outside the permitted addresses, including a port mismatch, keeps Save disabled. The editor and direct command name the allowed addresses and explain that any port must match.
4. AC4. A kept key remains removable after withdrawal of either permission. The editor names the missing permission or permissions and finishes the kept-key line with a period.
5. AC5. Technical section 19.4 records the editor's wording and status messages.

App TECHNICAL 5.3.4, 19.4, 19.5 and 19.6. Host TECHNICAL 19.4 owns origin parsing and key binding.
