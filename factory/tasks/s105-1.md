Subsystem: dist
Effort: medium
Depends on: none
Slice: S105 — a listed base cannot lead dist into the local network

## Goal

A base that dist reads because a listing or a provider hint named it (a listed read: 5.9, 5.11,
`read_link`) can no longer reach `localhost` or a local IP literal, neither directly nor through a
redirect: every redirect target of a listed read passes the same local-address rule as the base
(A35/A37), and the 5-redirect limit stays. `localhost.` and other trailing-dot host forms count as
local. And Eve's fetch of a release whose channel has a listed record, on a cache miss, no longer
stops at the record's base: when that base fails, the provider bases of 5.11 (Eve's own channel's
listings first, in trust order) are tried, as S104 does for a channel with no record. The deputy
decided the redirect rule (check each target, do not leave redirects under "Not protected"); no
open decision is left for this task.

## Acceptance

1. AC1 (redirect, channel read). A listed read (index read 5.9, provider read 5.11, `read_link`)
   whose base answers `head` or an entry with a 3xx `Location` on `localhost` or a local IP
   literal makes no request to that target; that base's read fails with
   `BadUrl { url: <target>, cause: "local address" }`, and the next base is tried as for any
   failed base. Tests: a test base is always local, so show the rule at the lowest level that can:
   a unit test of the redirect-following code with the target check as a parameter (local target
   refused before its request, relative `Location` resolved against the current URL, 5-hop limit),
   plus an integration test with `listed_local` false through a seam that lets only the first hop
   be local (a `#[cfg(test)]` or `pub(crate)` hook, no new public option) if that is cheap; else
   unit tests only, and say so in the report.
2. AC2 (redirect, package). The same holds for a package GET from a listed or hint base: a
   redirect to a local target is refused before any request to it, and on the provider path
   (5.11 step 3) the fetch moves to the next base as for `NotFound`/`Network`/`Timeout`.
3. AC3 (redirects elsewhere unchanged). A redirect from a listed base to a non-local target is
   still followed, at most 5 hops (the 6th is an error as today); a followed or chosen channel's
   own base (the participant's choice) follows redirects as today, local targets included.
   The whole-read timeout and body limits of 4.5 still bound the read across all hops.
4. AC4 (trailing dot). `local_base` is true for `http://localhost./`, `http://a.localhost./`,
   `http://localhost../` and other trailing-dot forms of a local name; an IPv4 literal with a
   trailing dot (`127.0.0.1.`) is local; `example.org.` is not. Extend
   `index::tests::ac8_local_literal_hosts`.
5. AC5 (listed record, cache miss). Given Eve has a listed record for Carol (not followed, not an
   index) whose base is dead, Carol's release is stored in Eve's log, the package is not in the
   cache, and Eve's own channel lists Carol at a live base: `fetch` returns the verified package
   from the live base, `Fetched.link` names the live base, and the record is unchanged (bases
   and times). The record's base is tried first; then the 5.11 bases in trust order, distinct,
   at most 4 in all. When every base fails, the error follows 5.11 step 4.
6. AC6. `cargo test -p watane-dist -- --include-ignored`, clippy and fmt pass.

## Interface

No public signature changes. Internal: the listed/not-listed distinction already reaches
`read_channel_entries(key, base, listed)`; carry it to the GET (`Dist::get`/`get_once`) and to the
package GET on listed/hint paths. A refused redirect is
`DistError::BadUrl { url: <target>, cause: "local address" }` (existing variant), and the check is
the existing `listed_local` option plus `index::local_base` (one rule for bases and targets).
Suggested mechanism (yours to choose): a second agent with `max_redirects(0)` for listed reads and
a loop that follows up to 5 `Location`s, resolving each against the current URL and checking it
before the request, all within the read's one deadline.
