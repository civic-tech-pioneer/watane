## Goal
J3 passes with GitHub as the host, on a local stand-in: Alice's coding agent runs
`watane-dev publish --push` against her real watane app; dev creates and pushes her site and mod
repositories (local bare remotes); the test serves a fresh clone of the pushed site repository as
Alice's site, Alice sets that URL in the app, the agent runs publish again to get the link, and Bob
installs from that link and sees Alice as the verified publisher. Test code only.
