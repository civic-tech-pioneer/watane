## Goal
One dist leftover (S57), re-checked against main `ec744f4` on 2026-11-20: still open. When every
provider base that served a channel lacks the wanted release, dist answers `StaleBases`
(src/fetch.rs:157), whose text (src/error.rs:98-103) reads "the 1 base(s) read hold an older copy of
the channel" and always calls the bases stale. Two faults: "1 base(s)" is not English, and when the
wanted slug appears in no release of the stored view at all (a name that may simply not exist), the
text still asserts the mirrors are behind, which dist cannot know.

After this task the count reads "1 base read holds" / "2 bases read hold", and the text claims a stale
copy only when the stored view holds the slug at some other version; when no release of the slug is
held at all, it states what dist saw (no release of `<slug>` on those bases) and both readings: it
may be newer than their copy, or the name may be wrong.

Decided here (not by you):
- `DistError::StaleBases` gains a field: `StaleBases { release: ReleaseRef, bases: usize, slug_held: bool }`.
  `slug_held` is true when, after the reads, the stored view of the channel holds at least one
  release (any version, withdrawn or not) with `release.slug`. Raised where it is raised today; no
  other path changes. The error is still `StaleBases` in both cases (node and app match it with
  `{ .. }` or a wildcard; do not touch them).
- Texts (exact; `<n base(s)>` is "1 base read holds" for 1, "<n> bases read hold" otherwise):
  - `slug_held: true`: `release <release> is not on any base that serves its channel: the <1 base
    read holds | n bases read hold> an older copy of the channel; follow the publisher's own link,
    or try again when the mirrors catch up`
  - `slug_held: false`: `release <release> is not on any base that serves its channel: the <1 base
    read holds | n bases read hold> no release of <slug>; it may be newer than their copy (follow
    the publisher's own link), or the name may be wrong`
  The Display needs a small helper (a `#[error("{}", ...)]` with a function), not two variants.
