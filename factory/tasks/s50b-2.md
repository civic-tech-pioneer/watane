## Goal
`watane-node --version` prints `watane-node 0.1.0` (the crate version) and exits 0, as
`watane --version` and `watane-dev --version` already do, so the installer and a person can ask each
of the three programs its version (install/TECHNICAL 11 stage 2, INST-F-18).

## Acceptance
- AC1 `watane-node --version` prints exactly `watane-node <CARGO_PKG_VERSION>\n` on stdout, nothing
  on stderr, exit 0, with no `--home` or `WATANE_NODE_HOME` needed. A test in
  `node/tests/program.rs` runs the built binary and checks it.
- AC2 The usage text lists `watane-node --version`; a unit test of `parse` (or the existing ones) covers it.
- AC3 One test each checks `watane --version` and `watane-dev --version` print `<name> <version>`
  and exit 0, if no such test exists yet (search `host/tests` and `dev/tests` first; if one exists,
  add nothing there). Only touch host/dev if such a test finds a difference.
