## Goal
A maker who runs `watane-dev serve` gets a preview in which Claude Code is dev's `fake-claude`: a
program that speaks Claude Code's stream-json and control protocol from a script, checks the host's
arguments, and logs what the host wrote. `serve` links it into `<P>/claude/`, writes the default
script if there is none, and starts the preview with `--fake-claude`. The template's AGENTS.md tells
the maker to commit `wit/deps/watane-host/host.wit` (S97's note: `check` and `serve` rewrite it).
## Acceptance
AC1. `fake-claude --version` prints `2.1.295 (Claude Code)`, or `<version> (Claude Code)` with the
     script's `version`. Unit or integration tests in `dev/tests/it/fake_claude.rs`.
AC2. Started with the fixed arguments of host 19.3 and a script beside it (`fake-claude.json`), it
     reads the host's `initialize`, answers it (`hook_on_failure_supported: true`; `hooks_applied: true`
     when the request holds hooks; the script's `initialize` overrides), writes a `system/init` line
     that holds what the launch arguments say (tools from `--tools=`, MCP servers none unless
     `--mcp-config`, agents from `--agents=`, permission mode from `--permission-mode=` with
     `manual` as `default`, plugins `["watane-run"]`), the script's `init` overriding any field, then
     runs the steps of dev 18.2. A test drives it over pipes with the default script of 18.4: after
     `initialize` and a `user` message holding "hi", it writes the delta, the message, the result and
     the idle line `{"type":"system","subtype":"session_state_changed","state":"idle"}` (compared as
     JSON with literals).
AC3. A missing fixed argument, or a forbidden one (`--bare`, `--permission-mode=auto`,
     `--permission-mode=bypassPermissions`, each of 18.2's list), exits 64 naming it on stderr.
AC4. `fake-claude.log` beside the script holds one JSON line for the arguments, one per environment
     variable, one per stdin line, in order.
AC5. A host line that no step awaits and that is not one of 19.3's writes (e.g. a second
     `initialize`, `set_permission_mode`) exits 70 and is logged. `expect-user` with `contains` that
     does not match exits 70.
AC6. Steps `raw` (`line` and `hex`), `sleep`, `exit {code}`, `crash`, `hang`, `ask`/`check` (written,
     `await` logs the host's answer), `cancel`, `expect-interrupt` behave as the 18.2 table says;
     one test each, cheap ones grouped.
AC7. `watane-dev serve` on a mod folder links (or copies, where links fail) `fake-claude` into
     `<P>/claude/fake-claude`, writes `<P>/claude/fake-claude.json` with the default of 18.4 only when
     absent (a maker's script is kept), and passes `--fake-claude <P>/claude/fake-claude` after
     `--preview` (the test checks the argument with dev's fake `watane`, `src/bin/fake-watane.rs`).
     With `fake-claude` not found beside `watane-dev` (9.1), `serve` and `doctor` give
     `preview.fake_claude_missing` (2.2) and `serve` starts without the flag.
AC8. The template's AGENTS.md says to commit `wit/deps/watane-host/host.wit` and that `check` and
     `serve` rewrite it to the host's copy; the template test that pins AGENTS.md is updated.
AC9. (Slow, `#[ignore]`, runs once s99-2 is on the branch.) `watane-dev serve` with the real `watane`
     on a mod with `claude-code`: a `claude-code.start` with `workspace: "scratch"` gets
     `initialized` and the fake's lines as items, and `fake-claude.log` shows the host's `user`
     message after a `say`.

## Interface
Takes from host (s99-2, fixed; do not wait for it to compile your fast tests):
- the program `watane` accepts `--fake-claude <path>` after `--preview <dir>`;
- the fixed arguments `-p --input-format=stream-json --output-format=stream-json --verbose
  --restricted --strict-mcp-config --system-prompt-snapshot=off --settings=<json>`, then one
  `--flag=value` per launch value;
- `initialize`: `{"type":"control_request","request_id":"<id>","request":{"subtype":"initialize",...}}`,
  answered `{"type":"control_response","response":{"subtype":"success","request_id":"<id>","response":{...}}}`;
- `say`: `{"type":"user","message":{"role":"user","content":"<text>"}}`; `compact`: the same with
  `/compact`; `interrupt`: `{"type":"control_request","request_id":"<id>","request":{"subtype":"interrupt"}}`;
  a deny to an ask: a `control_response` with `{"behavior":"deny","message":...}`.
- The idle line: `{"type":"system","subtype":"session_state_changed","state":"idle"}`.
Provides: the program `fake-claude` (feature `fake-claude`, default on, shipped with `watane-dev`).
