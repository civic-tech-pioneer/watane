## Goal
The release workflow's three actions run on Node 24 natively, so a release run shows no
forced-runtime warning; and `clean_mac::ac1_ac2_fresh_home_real_release` skips with its reason
(printed on stderr, test returns) instead of failing where there is no `target/release` build, so
`factory/check.sh` passes for install tasks in a fresh worktree.

## Acceptance
AC1. `.github/workflows/release.yml` pins `actions/checkout`, `actions/upload-artifact` and
     `actions/download-artifact` to full commit SHAs of a release whose `action.yml` says
     `runs: using: node24`. Verify it: `git fetch https://github.com/actions/<name> <tag>` into a
     scratch repo and `git show FETCH_HEAD:action.yml`. The trailing comment names the tag (e.g. `# v6.1.0`).
     Pick each action's latest release tag (`git ls-remote --tags`) whose action.yml says node24
     and pin its full 40-char commit SHA (dereference annotated tags: use the `^{}` line).
     Inputs that changed between v4 and the new major (e.g. download-artifact `path` semantics,
     upload-artifact `include-hidden-files`) are checked against each action's README and kept
     equivalent to today's behaviour.
AC2. `tests/it/workflow.rs` accepts the new pins (the rule that today demands the `v4` comment
     now demands the version comment of the pinned release) and still rejects every broken copy
     in `ac2_*` (an unpinned `@v4`, a tag ref, an extra action).
AC3. `ac1_ac2_fresh_home_real_release` (macOS, ignored) when `target/release/watane`,
     `watane-dev` or `watane-node` (or whatever `package.sh` needs) is missing: prints
     `skipped: no release build at <path>; run cargo build --release -p watane-host -p watane-dev -p watane-node`
     to stderr and returns (passes); with the build present it runs as today. It cannot run on
     Linux; make the check a small helper that compiles on every OS so `cargo test` covers it,
     and say in the report that the macOS run is the PO's.
AC4. TECHNICAL 7.1/7.2 name the pinned majors and that they run on node24; 12.x describes the
     skip and why (S55's leftover). Do not edit factory/PLAN.md.
