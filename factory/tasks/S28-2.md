## Goal
Carol chooses Ivy's index from its link. Her dist reads Ivy's channel with the usual
verification, then every channel of Ivy's read set (one level of includes), and keeps each listed
channel as a "listed" record that is neither followed nor chosen. A listed channel is read from
each base the listings give until one is current, so a stale mirror cannot hide a withdrawal; a
listed base on localhost or a local IP literal is never read; caps bound how many channels any
index makes Carol read; the own key is never read through a listing; a compromised index lists
nothing. Refresh reads in three passes and drops listed records no read set holds any more.

## Interface
Takes from S28-1: `ChannelView.listings`, `ListingInfo`, `Change::Listed/Unlisted`, `NotIndex`.
Provides (exact signatures of TECHNICAL 3): `choose_index`, `drop_index`, `indexes`,
`IndexView { view, included, mods, skipped }`, the step 4 `Options` fields with their defaults,
`ChannelView.index` and `listed_by` filled by `channel`, `followed`, `own`.
Provides to S28-3 (search), in `src/index.rs`, derived from stored entries and `follows.json`
only (no request):
```rust
pub(crate) struct ReadSet {
    pub index: PublicKey,                         // the own key first, then chosen indexes in key order
    pub whole: Vec<(PublicKey, Option<PublicKey>)>, // channels whose every release counts: the index (None), each read live include J (Some(J))
    pub mods: Vec<ListedMod>,                     // live lists of the walk, walk order
    pub skipped: usize,
}
pub(crate) struct ListedMod { pub channel: PublicKey, pub slug: Slug, pub through: Option<PublicKey>, pub note: String }
impl Dist { pub(crate) fn read_sets(&self) -> Result<Vec<ReadSet>, DistError>; }
```
`indexes()` and `listed_by` are built on `read_sets`. `IndexView.mods` counts listed mods that
have a stored release that is not withdrawn (as 5.10 step 2).
