## Goal

The four `front:` tests (`#[ignore = "front: takes the screen"]`, run only with
`--include-ignored` or `--ignored`) skip with a clear message when the Mac's
screen is locked, instead of failing. Today `App::front` (app/tests/support/driver.rs)
waits for 30 s of human idle time; a locked screen has a large idle time, so the
wait passes, the app starts in front mode, and the focus assertions fail
(`gui_isolation` ac1). After this task a locked screen is seen and the test
returns early, passing, with one stderr line saying it was skipped and why.

## Acceptance

AC1 Lock state is parsed purely. A new `pub fn screen_locked(output: &str) -> Option<bool>`
in app/tests/support/driver.rs reads the output of `ioreg -n Root -d1` and returns
`Some(true)` when it contains `"CGSSessionScreenIsLocked"=Yes`, `Some(false)` when it
contains the console session (`"kCGSSessionOnConsoleKey"=Yes`) without that lock key
set to Yes, and `None` when the output has no session dictionary at all (no
`IOConsoleUsers`). Test: a unit test in app/tests/support_selftest.rs (next to
`ac4_idle_time_parses_ioreg_nanoseconds`) with a locked line, an unlocked line, and
output with no session. Real lines look like
`"IOConsoleUsers" = ({"kCGSSessionOnConsoleKey"=Yes,...,"CGSSessionScreenIsLocked"=Yes,...})`
(the lock key is absent, not `No`, when unlocked).
AC2 `App::front` returns `Option<App>`. Before spawning, and on each poll of the idle
wait, it runs `ioreg -n Root -d1`; if the screen is locked it prints once to stderr
`front test skipped: the screen is locked (CGSSessionScreenIsLocked)` and returns `None`.
`None` from the parser (cannot tell) panics with a message naming ioreg, like the idle
wait does today; it is not evidence of an unlocked screen. Unlocked: unchanged
behaviour (idle wait, then spawn, `Some(app)`).
AC3 The four call sites (`gui_isolation.rs` ac1, `gui_shell.rs` at lines ~202, ~463,
~499) use `let Some(app) = App::front(...) else { return };`. The static check
`ac3_screen_assertions_require_front_constructor_and_ignore` in support_selftest.rs
still passes unchanged.
AC4 On this Mac with the screen locked, `cargo test --features driver -- --ignored front`
style runs of the four tests pass and each prints the skip line. (The foreman runs
them; you may run them if the screen is locked when you work; never run them on an
unlocked screen: they take it.)
