## Goal

J5 shows Carol's derived mod published as a real GitHub fork inside an organisation. The fake J5
(`ac2_j5_github`) has Carol publish with `--owner` an organisation that is not her gh login and checks
the fork landed there. The real J5 (`ac3_j5_real_github`, feature `real-github`) now lets dev fork
Alice's repository into `minmax-fund` itself (S53 could only pre-create Carol's repository, so
`forked` was false): the fork exists, its parent is Alice's repository, and its default branch is
`watane`. A probe by the foreman (2026-11-15) confirmed GitHub allows forking a repository into the
organisation that already owns it, with a new name.

## Acceptance

AC1 Fake J5 (`app/tests/j5.rs::ac2_j5_github`): Carol publishes with
`["publish", "--push", "--owner", "carols-club"]` (fake-gh user stays `carol`). Asserts change from
`remotes/carol/ratings` to `remotes/carols-club/ratings`: `forked == true`, `fake-gh-parent` is
`alice/reading-list`, HEAD is `refs/heads/watane`, Alice's tagged commit is an ancestor of `watane`,
the release tag is at `watane`, `main` equals Alice's `main`; `push.mod.repository` is
`https://github.com/carols-club/ratings`; `remotes/carol/ratings` does not exist. Alice's part is
unchanged (no `--owner`).

AC2 Harness (`app/tests/support/github.rs`): `reserve(&mut self) -> String` returns a fresh
`minmax-fund/watane-j-<r>` name exactly like `create` (same random rule, same "must answer 404 or
panic" check, recorded for deletion on Drop) but does not create the repository. `create` uses it.
Drop deletes reserved names that exist and ignores a 404 on a reserved name that was never created
(no panic, no noisy line for that case). The deletion guard (prefix assertion) applies to every name.

AC3 Real J5 (`ac3_j5_real_github`): Carol's mod repository is no longer pre-created. The harness
reserves `minmax-fund/watane-j-<r>`; Carol's mod uses the slug `watane-j-<r>` (rewrite the package
name `mods:ratings` in her `wit/world.wit`, and anything else that must match the slug, so that
`publish` reads it as that slug; no `repository` in her mod.toml). Carol's site keeps a pre-created
repository through `site_origin`. Carol runs `publish --push --owner minmax-fund`. Asserts:
`ok`, exit 0, no warnings, `push.mod.forked == true`,
`push.mod.repository == https://github.com/<reserved>`; `gh api repos/<reserved>` gives
`.parent.full_name` = Alice's mod repository name and `.default_branch` = `watane`; a fresh clone has
Carol's release tag and Alice's tagged commit is an ancestor of it. Alice's part is unchanged.

AC4 Everything still compiles without the feature (`cargo test -p watane-app --features driver
--no-run`) and with it (`--features real-github --no-run`); clippy clean with both.
