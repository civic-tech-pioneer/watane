## Goal

Pin the redirect contract with focused tests, and clarify the descriptions of
redirect hops and derived index choices.

## Acceptance

1. AC1. An HTTP redirect to HTTPS passes the target check and reaches the next
   hop. An in-process unit test supplies the responses.
2. AC2. A listed read with two redirects, where the second target has an unsupported
   scheme, returns the originally requested URL in BadUrl. A loopback test
   verifies exactly which requests arrived.
3. AC3. The redirect and derived-base helper comments describe their behavior.
   The choice of a derived index refers to the listed-record policy in 5.9.
