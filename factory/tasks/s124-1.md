## Goal
net's tests that share the per-key connection and byte budget stop flaking on timing, and net's
own errors name the true party. After this task: (a) every test in `net/tests/it/` that sends
several requests from one unknown key against the default budget (`budget::s9...` and each like
it) asserts its refusal code without racing the budget, as S106 did for `pair::s4` (a fresh key
per probe, or a fixture budget sized for its trials; and a test still proves the production
budget refuses); (b) a full machine that answered but did not serve a package, or whose copy
failed its check, no longer reads "node X is unreachable"; (c) the holder of this machine
refusing a page `need` pulled no longer reads `Unreachable { node }` naming the full machine:
it names this machine; (d) a local failure during a package download (this machine's temp file,
or the holder not keeping it) stays `Io`, names no machine, and its text does not show the temp
file path.

## Interface
Provides to node (task s124-3), fixed:
```rust
// in watane_net::NetError
#[error("node {} did not serve {cause}", node.short())]
NotServed { node: NodeKey, cause: String },        // cause e.g. "package ab12cd34: it does not have it, or its copy failed its check"
#[error("this machine did not take channel {channel}: {cause}")]
NotTaken { channel: PublicKey, cause: String },     // PublicKey is the type `need` takes
```
`NotServed` names another machine; `NotTaken` and `Io` name this machine. No other variant
changes name or text. Display wording inside `cause` is net's to choose, within AC2/AC4.
