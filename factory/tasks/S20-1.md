Slice: S20 — A mod becomes a release: pkg makes the release body of a mod and its package, encodes it in one canonical form, refuses any other bytes naming the cause, and confirms a body against a package.

## Goal
pkg stage 7: `release.rs`. From a mod and its package, `Release::new` makes the release body
(slug, version, name, summary, package id and size, source flag, offers, events, grants,
origin); `encode` writes it as deterministic CBOR; `decode` gives it back and refuses every
other form with an error that names the cause; `check` confirms a body against a package's mod
or names the first field that differs. dist publishes these bytes and the host verifies them
(a later slice); nothing here signs.

## Acceptance
- AC1 (A21, `release_golden`) `Release::new(&Mod::read(hello)?, &pack(hello, false)?)` then
  `encode()` equals the 73-byte hex of TECHNICAL 7.3; `decode` of that hex equals a literal
  `Release` written in the test.
- AC2 (`release_golden`) A literal `Release` with the four grants of 7.3 (K = 32 × `0x01`)
  encodes its grant array to the grant hex of 7.3; one with origin `K/reading-list@0.1.0`
  encodes the origin hex of 7.3; both decode back to the same struct.
- AC3 (A22) `Release::new` for fixture `recommendations` (local provider `reading-list`):
  `Err(ReleaseError::LocalProvider { slug })` with slug `reading-list`; the message names it.
- AC4 (A23, `release_refusals`) Hand-edited 7.3 hex, each refused by `decode`: a non-shortest
  integer (`NotCanonical`), an indefinite array (`NotCanonical`), a 13th item, trailing bytes
  (`NotCanonical`), format `2`, unsorted offers, a `null` grant publisher (`LocalProvider`),
  an offer of another package, a bad slug text, a package id of 31 bytes, more than
  `MAX_RELEASE_BYTES` (`TooLarge`, before any parsing). Each error's text names the cause.
- AC5 (A24, `release_check`) A body whose `summary` differs from the package's `mod.toml`:
  `check` gives `Mismatch { field: "summary" }`; one case per other field of 7.1 gives its
  field name (literal structs, field names as in 7.1).
- AC6 Round trip: for `hello` and `reading-list` packs, `decode(encode(r)) == r`,
  `r.package == package.id()`, and `r.check(&package.unpack(tmp)?, &package)` is `Ok`.
  A package with one changed byte fails `check` with field `package`.
- AC7 `cargo test -p watane-pkg`, clippy `--all-targets -D warnings`, `cargo fmt --check` pass.
