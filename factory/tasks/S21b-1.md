## Goal
host build stage 8 (`host/TECHNICAL.md` 15, row "8 Releases"): `Source::Release { package, entry }`
plans and installs a signed release. The host checks the entry's kind, decodes the release body,
compares the package hash and, after unpack, `body.check(&mod, &package)`, in that order (5.2);
the first failure is `HostError::Verify { check, reason }` (code `verify`, JSON `"check"`). A
planned release carries its `ReleaseRef` and publisher, so Bob's consent view can show Alice as the
verified publisher; the installed mod keeps both across a restart.

## Acceptance
- AC1 (S31, `tests/verify.rs`) a package of fixture `counter` (`pack(dir, false)`) and a release
  body (`Release::new` ... `encode`) signed by a `watane_log::Log` on a temp dir with
  `append(RELEASE_KIND, ..)`: `plan` gives one entry with `publisher == Some(K)`, identity
  `K/counter` and `release` text `K/counter@0.1.0`, both built from `Log::identity()` and literals.
- AC2 (S32) one byte of a file inside the package changed (repack the changed folder, keep the
  old release): `verify` with check `package_hash`. One byte of the entry bytes changed:
  `Entry::decode` is `Err` (the host is never reached). A release signed by K that names this
  package's hash but another summary: check `mismatch`, and the message names `summary`.
- AC3 an entry of another kind: check `kind`; a `RELEASE_KIND` entry whose body is not a release:
  check `release_body`. Each error's JSON (`HostError` serialize as in 2.x) carries `"code":"verify"`
  and `"check":"<check>"`.
- AC4 a home (`Mode::Home` with an approving test `Confirm`) installs the release plan:
  `InstalledMod.release == Some(K/counter@0.1.0)` and its publisher is K; after drop and
  `Host::open` of the same home, `get` still shows both and the mod's page/call still works (the
  recovery of 4.3 does not treat the release-installed folder as uncommitted).
- AC5 an `extra_api` route passed to `serve` receives a 1 MiB POST body unchanged through host's
  API guards (app's `/api/publish` sets its own 64 MiB limit; host's 64 KiB applies only to its own
  routes, `host/TECHNICAL.md` 17 "asked of host").
- AC6 `pub use {watane_log, watane_pkg}` from the crate root (2.1); app needs no direct `watane-log`
  dependency.
- AC7 `cargo test -p watane-host` (default run), `cargo clippy -p watane-host --all-targets -- -D
  warnings`, `cargo fmt --check` pass.
