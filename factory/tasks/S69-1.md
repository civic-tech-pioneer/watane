## Goal
A maker's agent that writes S65's `menu` (a shell whose own outlet is named like its slug) and
`item` (a mod that answers it) from `watane-dev new` gets four things right on the first try:
(1) the guide and the "duplicate item named <slug>" error both tell it to rename the world when an
own interface is named like the slug; (2) a contract file that fakes a function the interface does
not have is refused, naming that function and the interface's real functions, instead of the fake
being silently ignored; (3) `check --json` lists collect outlets under a new `collects` field
beside `events`; (4) `add`'s `next` says that the `export` lines (result.subscriptions) are how the
mod answers the provider's events and collects.
