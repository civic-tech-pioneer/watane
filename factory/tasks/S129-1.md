Slice: S129 — A maker previews a checked provider against dev's scripted judge

## Goal
Bind the scripted judge for a development preview while retaining the HTTPS stream checks and participant-home behavior.

## Acceptance
1. A script with plays enables a judge account for a granted POST to the program's judge origin. It supplies the fixture key and dials only the program's loopback endpoint using its CA and the requested TLS name.
2. Wrong origins, methods, grants and forbidden headers keep their 19.4 refusals. Failure never retries a public connection.
3. Without plays, the preview judge is unavailable. Home and release guards also cover Judge.
4. Startup ready JSON exposes an optional `judge_origin` string for consumers when the fixture is bound. It contains only the canonical origin.

## Spec
host TECHNICAL 19.4, 19.9 and spec TECHNICAL W39.

## Interface
Existing `--scripted-openai <program> --openai-script <file>`. The script has optional `judge_key` and `plays`. The program's existing ready line has `judge_addr` and `judge_origin`. Host preview ready JSON adds optional `judge_origin: String`.
