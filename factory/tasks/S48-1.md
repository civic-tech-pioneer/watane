## Goal
When Eve unfollows a channel she never followed, dist says that the channel is not followed, so
there is nothing to unfollow; it no longer tells her to "follow the publisher's link". When a
provider's first hint base (in trust order) is a stale mirror (its read gives `Current` or
`Behind` but the stored view still lacks the wanted release), dist reads the next hint base
instead of stopping there and answering "unknown release"; the base that finally serves the
release is `Fetched.link`'s base and the package source. dist TECHNICAL 3.1 and 5.11 step 4 show
the variant shapes that S45 introduced (DD-31), and the new variant.

## Interface
New `DistError::NothingToUnfollow { channel: PublicKey }` (public enum, additive), returned only
by `Dist::unfollow`. `NotFollowed { channel, local_only }` unchanged and no longer returned by
`unfollow`. `fetch_for`/`fetch` signatures unchanged. No other crate names either variant
(checked: app, host, dev).
