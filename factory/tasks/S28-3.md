## Goal
Carol searches "reading" and gets Alice's reading list: the newest version that Alice's own
verified channel does not withdraw, with Alice's profile name, why it is in her search set
("listed by Ivy" with Ivy's note), and a mark when Alice's channel could not be read since the
last good read. Search reads only what dist stored, so it works offline. The dist half of J4 runs
end to end.
