## Goal
After this task the app can plan an install with a bind: Eve picked K3's `shelf` for `recs`, whose
`deps.json` pins K1's `shelf`. `Host::plan_with(sources, binds)` links that consumer to the picked
mod when it has the same slug and offers every interface the consumer needs; the bind is shown in
the plan and in the installed mod, is confirmed like a new grant, is kept in `installed.json`
across restarts and updates, and is deleted when the picked mod is removed. A preview links a
provider by slug and interface, whatever its publisher (W27). The local API stays without binds.
