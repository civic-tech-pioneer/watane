## Goal

Net's rebuild reports the blob store's reopen error if the old database is
still locked after teardown times out. Net's private Windows storage uses the
shared directory check.

## Acceptance

1. AC1. When a store shutdown stalls past STORE_WAIT and redb still holds the
   old database open, changing a switch returns the reopen's I/O error.
2. AC2. Windows node keys and blob folders keep the existing directory and
   key validation, including refusal of an exposed ACL.
3. AC3. TECHNICAL names STORE_WAIT and the behavior of a reopen after a
   timeout. Storage documents the Windows folder check and key publish.

## Spec

net/TECHNICAL.md 4.5, 5.1, 5.8 and 9 (N4). log/TECHNICAL.md 4.7.

## Interface

Uses `watane_log_windows_fs::private_dir(path: &Path) -> Result<File, PrivateDirError>`
from s116-1. The helper preserves directory handles and distinguishes
`PrivateDirError::Io(io::Error)` from `PrivateDirError::Invalid(io::Error)`.
No public net interface changes.

## Changed tests

None. Existing keyfile and reach tests cover the current contract and continue

## Out of scope

Changing the storage format, the timeout length or retry policy.
