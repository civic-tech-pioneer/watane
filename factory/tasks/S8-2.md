Slice: S8 — Same mod, same id: the preview host installs a mod folder under the same canonical package id that `pkg::pack` gives.

## Goal
The host installs a preview folder through pkg instead of its own copy and temporary digest
(host 4.2 steps 1 and 2): `pack(dir, false)` gives the package and its id, and
`package.unpack(staging)` gives the staged `Mod`. The installed mod's package id is the canonical
`PackageId` that pack gives, so a host and dev agree on it. Both `ponytail` comments in
`catalog.rs`, `copy_folder` and `digest` go, and the S1/S2 cut text about the temporary digest in
host `TECHNICAL.md` (15, Q12) is updated.

## Acceptance
- AC1 Installing a mod fixture folder (with `logic.wasm`, and one page-only) gives an
  `InstalledMod.package` equal to `watane_pkg::pack(folder, false)?.id()`; the catalog on disk
  holds the same id, and reopening the home keeps it.
- AC2 Files pack skips stay out of the installed mod: a folder with `.git/x`, `.hidden`,
  `logic/target/x` and `logic/src/lib.rs` installs; none of those exist under `mods/<local>/`, and
  the id equals the pack id (pack without source).
- AC3 Installing the same unchanged folder again is `Unchanged` (no new generation); changing one
  byte of `ui/index.html` gives a new package id and an update; pages reload only when the id
  changes (S3 behaviour stays).
- AC4 A `PackageError` from pack or unpack (a symbolic link in `ui/`, a folder over the size
  limit) is `invalid_mod` naming the folder; no staging folder is left in the home.
- AC5 `cargo test -p watane-host` (and the program tests with `WATANE_BIN` as before), clippy
  `-D warnings --all-targets --all-features`, `cargo fmt --check` pass; existing tests stay green
  (update only literals that encoded the old digest).

## Spec
`host/TECHNICAL.md` 4.1, 4.2 steps 1 to 4, 4.3, 15 (S1 and S2 cuts), Q12, and the pkg interface
it lists (`pack`, `Package::{id, unpack}`). `pkg/TECHNICAL.md` 6.4 (read only).

## Interface
Takes from pkg (exists, unchanged): `watane_pkg::pack(&Path, bool) -> Result<Package, PackageError>`,
`Package::id() -> PackageId`, `Package::unpack(&Path) -> Result<Mod, PackageError>` (the
destination must not exist; its parent must). Nothing with the sibling task (S8-1, dev).
