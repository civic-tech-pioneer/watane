## Goal
Item 5 of the product owner's last round (the deputy on PR #15, 2026-11-23 18:37): opening a home
never kills a process group that reused a pid recorded in `<home>/runs/pids`, and the version probe
never kills its group after its child was reaped. As host TECHNICAL 3.1 step 3 and 19.3 (the run:
Process; step 5, the sentence on the version probe) now state it.
## Acceptance
AC1. The adversary's red test from factory/tasks/s100-followup-clean-runs.md (`adv_s100_clean_runs::adv_s100_open_kills_a_group_that_reused_a_recorded_pid`):
     add it to host/src/agent/claude/run.rs unchanged, see it fail, then make it pass.
AC2. A `runs/pids` record is `pgid boot-id start-time` (one line per run); a run writes its record
     when it starts and removes it when its group is killed and reaped. `clean_runs` kills a recorded
     group only when the boot id matches the current one and the leader's start time matches;
     a malformed or old-format line (pgid alone), a different boot id, a dead leader or a different
     start time: dropped unkilled. Unit tests for each case with literal lines; one test that a
     real recorded run (a `sleep` started in its own group and recorded) IS killed at open.
     Linux: boot id `/proc/sys/kernel/random/boot_id`, start time field 22 of `/proc/<pid>/stat`
     (after the `)` of the comm field). macOS: `sysctl kern.boottime` and `kern.proc.pid.<pid>`
     `kp_proc.p_starttime` (via `rustix` if it offers it, else a `sysctl` subprocess as `probe` runs
     `claude`; no `unsafe`). If macOS cannot be done without `unsafe` or a new dependency, report it.
AC3. `probe()` (`claude --version`): kill the group, if needed, before its child is reaped (the same
     WNOWAIT pattern as the waiter, or kill then reap in one thread), never after. Test: the
     reaped-then-killed order cannot happen (a seam recording kill vs reap order, or a unit test of
     the helper).
AC4. `cargo test -p watane-host` (default), clippy -p watane-host --all-targets, nightly fmt clean;
     macOS compiles (cfg both paths; CI's macos job is the check).
