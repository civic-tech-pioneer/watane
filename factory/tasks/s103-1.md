## Goal
A mod that holds `claude-code` can start Claude Code in a folder Alice picked, not only in a
scratch workspace. The first start in a folder new for (origin client, provider) does not start
`claude`: the stream gets `consent-pending` once, the host asks the app through
`Confirm::consent`, and only after `Granted` does the run start (so `initialized` never comes
before the consent). `Refused`, a dropped answer or 600 s ends the stream `consent-refused`.
The consent is kept in `installed.json` on the origin client's record; `Host::withdraw_consent`
takes it back and at once ends every stream that depends on it (`gone`, `claude` killed), also
mid-turn. The consent types (`Consent`, `ConsentRequest`, `ConsentAnswer`) are defined here for
all three kinds, so the app (s103-3) and agent tools (s103-2) build on them.
Open decisions this task makes at the boundary, within what the spec now states (the foreman
wrote them into host TECHNICAL on this branch; follow them, and settle any detail they leave
open in the fail-closed direction, writing it into the spec): the key of a workspace consent
names `via` (18 Q38 (b)); the protected write paths per workspace root (18 Q49 (a)); session ids
owned per origin client (18 Q50 (a)); a picked folder that is not NFC is refused.

## Interface
Provides (fixed; s103-2 and s103-3 compile against these, in `watane_host`, re-exported at the
crate root like `Confirm`):
```rust
pub enum Consent { Workspace { via: String, folder: String }, Account { via: String, account: String },
                   Toolset { toolset: String, functions: Vec<String> } }
impl Consent { pub fn parse(what: &str) -> Result<Consent, HostError>; }   // + Display (the `what` text)
pub struct ConsentRequest { pub origin: LocalName, pub via: LocalName, pub consent: Consent,
                            pub profile: Option<String>, pub functions: Vec<String> }
pub enum ConsentAnswer { Granted, Refused }
// trait Confirm gains, default Refused:
fn consent(&self, request: ConsentRequest) -> Pin<Box<dyn Future<Output = ConsentAnswer> + Send>>;
impl Host { pub fn withdraw_consent(&self, local: &LocalName, consent: &Consent) -> Result<(), HostError>; }
// InstalledMod gains: #[serde(default)] pub consents: Vec<Consent>;
```
`withdraw_consent` matches by the `what` key (a toolset by name, whatever its functions). It also
calls a crate-private hook that s103-2 fills to close dependent agent-tool handles; leave a
clearly named function (`agent::consent::withdrawn(&Consent, origin identity)` or similar) that
today ends the dependent streams.
