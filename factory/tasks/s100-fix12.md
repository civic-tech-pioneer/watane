## Goal
The end of a run is bounded with no exception but the reaper: the stdin writer never starts a write
after its give-up deadline, a start whose write end cannot be made non-blocking fails closed, and
the `ask-resolved` items that close asks go on the stream past its in-flight limit, so the drain
never waits on a consumer. Review r3 of PR #15, F3.1, F3.2, F3.6, as host TECHNICAL 19.3 step 5
("The end of a run is bounded ...") and the argument-order paragraph now state them.
