## Goal
Five fixes in check, build and step 5 name the wrong cause or a thing that does not exist. After
this task each says what is really there:
1. deps.json self entry (dev/src/check.rs ~135 and ~141): the fix "Ask before deleting
   wit/deps/<slug>/ and mods:<slug> from deps.json: a mod cannot depend on itself" names
   `wit/deps/<slug>/` even when that folder does not exist. Name it only when `<dir>/wit/deps/<slug>`
   exists; else `Ask before deleting mods:<slug> from deps.json: a mod cannot depend on itself`.
   `mod_problems_for_slug` has no folder today: pass what it needs (the mod folder, or a bool
   computed by the caller at check.rs ~215) — your choice, keep it small. The cycle fix in
   dev/src/deps.rs ~125 follows the same rule (name `wit/deps/<slug>/` only if it exists).
2. `repository` fix (check.rs ~157): prints the literal `https://github.com/<owner>/<slug>` though
   the mod's slug is known (`own_slug`). With a slug: `.../<owner>/<the slug>`; without one, keep
   `<slug>`.
3. `mod.self_dependency` from `add --release` (dev/src/build_on.rs ~255): fix "Pass the folder of
   another mod to add" is wrong for a release. New fix: `Pass the link or release of another mod to
   add --release`. The local `add` (deps.rs ~254) keeps its text.
4. `usage.no_source` (build_on.rs ~289): says "its publisher published it with --no-source", but
   a release also holds no source when the mod had no logic source and no `tests/` (a prebuilt mod,
   pkg/src/package.rs `class`). New message: `the release <ReleaseRef> holds no source (no
   logic/Cargo.toml, logic/src/ or tests/)`. Fix unchanged.
5. `build.reads_outside` (dev/src/builder.rs ~365): when the read path ends in `.wit` the cause is
   almost always a `wit_bindgen::generate!` path (left by a rename or copied from another mod), not
   an `include_*!`. For such a path the fix is `Point wit_bindgen::generate! in logic/src at this
   mod's own wit/ folder (path: "../wit"), not at <path>`; other paths keep today's fix.
