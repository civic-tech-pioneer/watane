     an equivalent, so the writer's blocked write fails); the writer and any join helper end within
     the second bound; an answer whose write completed before teardown has its `answered` before
     `ended` (test: a writer that completes during teardown — via a fixture or a unit test of the
     teardown function with a fake writer); a write that fails pushes none. No detached thread
     survives (a unit test of the teardown helper that the threads have ended).

     `before` file): no item is pushed for it; after the answer passes step 2, the first line the

     answer that fails step 2, the fake's log holds no line after `initialize`.
