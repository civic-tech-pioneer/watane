## Goal
A mod can give its agents tools: `agent-tools.open(toolsets)` returns a handle at once; each
toolset new for the origin client (or whose current functions are not all in the stored list)
waits for Alice's toolset consent, and until then `describe` and `call` fail
`consent-pending(what)`. After `Granted` the handle lists the consented tools with their
`@parallel`/`@idempotent` annotations, `call` runs a tool as a job whose result is the one item
of a host stream, a repeated key returns the same stream, and a `claude-code` launch with
`agent-handle` hands `claude` the handle's MCP server on fd 3 (`/mcp/agent`). A withdrawn
toolset consent closes the dependent handles at once; `remove` and a `grant` of `Manage` drop a
mod's names from every stored list. This builds H4 (host 19.5) and lifts the "an agent handle
waits for stage A3" cut.
