Effort: medium

Slice: S50b — the install script and its archive (install stages 1 to 3)

## Goal
`install/install.sh` exists and does everything install/TECHNICAL 3 and 8 say: install, upgrade,
reinstall, `--status`, `--uninstall`, the toolchain offer on `/dev/tty`, the refusals, the journaled
swap with its rollback and recovery after a kill. A new tests-only crate `watane-install` runs it in
`cargo test` on Linux against a fake release served by `tiny_http`, with every Darwin-only tool
(`uname`, `sw_vers`, `sysctl`, `xattr`, `xcode-select`, `id`, `rustup`, `rustc`, and the fault fakes
`mv`, `rm`) faked first on `PATH`, and answers typed on a real pseudo-terminal via `script(1)`.
This is stage 1 of install/TECHNICAL 11.

## Acceptance
- AC1 The crate `watane-install` at `install/` (TECHNICAL 1: `Cargo.toml`, `src/lib.rs` with one
  `//!` line and no code, dev-dependencies `tempfile` and `tiny_http` only) is a member of the root
  `Cargo.toml`; `cargo hakari generate` was run; `Cargo.lock` updated.
- AC2 Each scenario INST-S-1 to INST-S-22, 26 to 28, 30 and 31 of install/FUNCTIONAL.md is one test
  (or more) in `install/tests/script.rs`, named `inst_s<n>_...`, asserting its oracle column; all
  pass with `cargo test -p watane-install -- --include-ignored` on Linux. Tests that answer on a
  pseudo-terminal are `#[ignore = "slow: needs a pseudo-terminal from script(1)"]`.
- AC3 The test harness follows TECHNICAL 12.1: cleared environment, temporary `HOME` and `TMPDIR`,
  `PATH` = fakes dir + a symlink dir of only the 3.3 tools, `perl`/`script` started by absolute
  path, no-terminal runs under `setsid` (perl POSIX), the script under test is a copy with
  `@RELEASE@` replaced (as package.sh will do), the fake archive built by the test with the layout
  of TECHNICAL 4.2 (shell-script programs printing `<name> <version>`). No test reaches the internet.
- AC4 `install.sh` is POSIX `sh` (no bash-isms; run `shellcheck -s sh` if installed, else
  `sh -n` and `dash -n` if present), uses only the tools of TECHNICAL 3.3, prints exactly the texts
  of 3.9, 3.10 and 6.2, and has no test-only branch beyond `WATANE_RELEASE_BASE` and
  `WATANE_RUSTUP_URL`.
- AC5 The swap of 3.6 and 3.6.1 (journal, `.old.<pid>`, `.new.<pid>`, receipt last, undo on failure
  and on HUP/INT/TERM, recovery of a dead pid's journal, exit 5 on a live one) is implemented in
  full, since S50b-3 adds INST-S-32 to 35 against it. INST-S-14 (a failed swap rolls back) passes here.
- AC6 The checkout copy `install/install.sh` (holding `@RELEASE@`) refuses to run without
  `--release`/`WATANE_RELEASE` (3.1): a test shows exit 1 and `not a version: @RELEASE@`.

## Interface
Provides to s50b-3 (fixed): `install/tests/support/mod.rs` exposes helpers that s50b-3 reuses to
run the script against a fake release (building a fake archive of a given version, serving it,
running the script with or without a terminal, listing a tree); s50b-3 may extend this module.
The fake `mv` and `rm` of 12.1 (fail or sleep on a pattern a test file names) live in
`install/tests/fakes/` now, even where only INST-S-32/33 use their sleep mode.
