Slice: S123 — Alice's install, upgrade and uninstall say the true thing

## Goal

Alice can tell what happened and what remains when installing, upgrading, declining the toolchain offer, interrupting either prompt, or uninstalling. Keep the existing install and deletion boundaries.

## Acceptance

1. AC1: A failed swap restores the prior state without claiming a broken installation works. Refusals and skipped entries show home-relative paths where applicable. A partial uninstall identifies that outcome. Ctrl-C at either prompt prints the state on its own line. Toolchain retry advice uses the chosen source or command and a usable doctor path. Preserve already-correct behavior and cover gaps at the lowest level, using a PTY only for actual terminal behavior.
2. AC2: Uninstall and interrupted fresh installs remove empty install-created folders, including bin, watane-dev share and Applications where applicable. Existing user folders, populated folders and relinked folders remain safe.
3. AC3: Piping status into a reader that closes after the first line produces no broken-pipe diagnostic. Preserve signal cleanup and check the pipe exit behavior on Linux and macOS.
4. AC4: Rustup stdout and stderr cannot interleave watane's frame. A failed rustup or rustup-download step identifies the step and gives relevant retry advice.
5. AC5: A unit case exercises the dead-PID skip in check_foreign, with a deterministic oracle.
