guard it carries is pinned by a test that fails without it. If `~/.local/bin` is relinked to the
home itself while files are staged, she reads "your home folder itself", never a bare `~`.

checks in `install.sh` are removed or pinned, and each `slow:` reason says what only that test
proves.
