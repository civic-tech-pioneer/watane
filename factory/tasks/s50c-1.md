## Goal
Close S50b's and S50b-fix's open risks in `install.sh` before the first release, as the
spec now says (the foreman wrote the spec; implement it):
1. The receipt records each install folder's resolved path (`resolved <folder> <R>`, 8.1),
   and a removal read from a receipt is skipped when its folder now resolves elsewhere
   (8.5 rule 4), so a link made after the install inside the home cannot let a receipt
   line empty another folder.
2. Two runs at once are excluded by a lock `~/.watane-install.lock` (3.6.2), taken at
   step 6 of an install and step 1 of an uninstall, removed by the exit trap of the run
   that made it, never broken.
3. The undo restores `receipt.old.<pid>` only when the journal holds `moved <receipt>`
   (3.6 step 4), so a `cp -p` cut short never replaces a whole receipt.
4. 3.6 step 0 does nothing when the receipt's own path is not allowed by 8.5 (no
   `clean_stale` there: stale names may be the only evidence while a journal exists).
