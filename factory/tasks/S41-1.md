## Goal
A mod folder's `mod.toml` may hold `repository = "https://..."`. `Mod::read` accepts a valid URL
and `Mod::repository()` gives it back exactly as written; a bad one is refused with one
violation (rule `mod-toml`, file `mod.toml`) whose message is exactly the one pkg 4.2's table
gives for the first failing check. Since `mod.toml` is always in the package, a packed mod with
`repository` unpacks and reads back with the same text. This is pkg build stage 8 (TECHNICAL 12).

## Acceptance
Unit tests in `pkg/src/meta.rs` for the grammar and messages (the lowest level); one
integration test in a new `pkg/tests/mod_toml_repository.rs` for `Mod::read` and the package
round trip (it may use `support::built_fixture("hello")` or the existing fixture helpers).
- AC1 Accepted, text given back: `https://github.com/alice/reading-list`,
  `https://git.example.org:8443/a/b-c.d_e~f%20`, `https://h`, and a URL of exactly 256 bytes
  (`https://h/` followed by `a` up to 256). `Mod::repository()` returns `Some(<the text>)`; a
  mod.toml without the key gives `None`.
- AC2 Refused with exactly these messages (pkg 4.2 table, first failing check wins), each one
  violation, rule `Rule::ModToml`, file `mod.toml`:
  - a 257-byte URL → `` `repository` is longer than 256 bytes ``
  - `http://github.com/a/b`, and a non-string value (`repository = 1`, `repository = ["x"]`) →
    `` `repository` must start with https:// ``
  - `https://user@github.com/a/b`, `https://user:pw@h/x` →
    `` `repository` must not hold a user name or password ``
  - `https://`, `https:///a` → `` `repository` has no host ``
  - `https://h/a b`, `https://h/a?b=c`, `https://h/#x`, `https://h:`, `https://h:123456`,
    `https://a..b`, `https://h\u{7}` → `` `repository` may hold only letters, digits and - . _ ~ / % after the host ``
  The test writes the expected strings literally (not built by calling the code under test).
- AC3 Round trip: the `hello` fixture with `repository = "https://github.com/alice/hello"` added
  to its `mod.toml` → `pack` succeeds, `unpack` (or `Package::from_bytes` + unpack) into a new
  folder, `Mod::read` of that folder → `repository()` is that text. The fixture without the line
  packs to the same bytes and id as before (goldens unchanged).
- AC4 `cargo test -p watane-pkg -- --include-ignored` (except the `regenerate_fixtures` test),
  `cargo clippy -p watane-pkg --all-targets -- -D warnings`, `cargo fmt --check` green.
