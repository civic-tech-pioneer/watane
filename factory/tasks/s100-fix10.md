## Goal
The stage B host load test fails when its workload or its interrupt measure is wrong, and its
writer-share breakdown is measured, not guessed. Review r2 of PR #15, F2.5 and F2.6.
## Acceptance
AC1 (F2.5). Per stream, the test asserts the delta rate and the entry rate (counts over the run
     within ±10% of 50/s and 5/s), each entry's text size (4096 bytes), and that the `result` it
     times for the interrupt is the one the interrupt caused (subtype `error_during_execution`, or a
     marker the fake writes for an interrupted turn, written after the interrupt stamp); cancel to
     `ended` correlated to the measured cancel. A scratch change of the workload to `55 0 4096 10.2`
     must fail the test (say so in the report; do not commit it).
AC2 (F2.5). Item delay: p95 per session, and the asserted figure is the worst session's p95 (as the
     record says), or the record is reworded to "pooled p95"; pick one and make record and test agree.
AC3 (F2.6). Writer busy measured by owner: time the host's own commits apart from the consumers'
     (a label or counter on the commit path that `Host::test_stats` exposes, or the fixture's own
     commit timing), or label the breakdown in the record as an estimate. Prefer measuring.
AC4. 3 passes in a row of `cd host && cargo test --test it agent_load:: -- --include-ignored`
     with nothing else running; record in host 15 updated; clippy, nightly fmt clean.
