## Goal
A mod can propose itself as the participant's main mod with `main = true` in `mod.toml`. pkg reads
and checks the key and gives it as `Mod::main()`. pkg stage 10 (pkg/TECHNICAL.md 12, row 10).

## Acceptance
- AC1 (A28) the fixture `hello` copied with `main = true` added to `mod.toml`: `Mod::read` succeeds
  and `main()` is true; the unchanged `hello`: `main()` is false.
- AC2 (A29) `main = "yes"`: refused, rule `mod-toml`, file `mod.toml`, message
  `` `main` must be true or false ``. `main = true` with no `ui/index.html`: refused, rule
  `mod-toml`, message `` `main` needs a page (ui/index.html) ``.
- AC3 New test file `pkg/tests/mod_toml_main.rs` holds AC1 and AC2 (pattern:
  `pkg/tests/mod_toml_repository.rs`). `cargo test -p watane-pkg`, clippy `-D warnings` and
  `cargo fmt --check` pass.

## Spec
- pkg/TECHNICAL.md 4.2 (`main`, the paragraph after `repository`), the API block (`pub fn main`),
  the test row `mod_toml_main`, 12 row 10. pkg/FUNCTIONAL.md A28, A29.

- Provides: `impl Mod { pub fn main(&self) -> bool }` (false when the key is absent). The release
