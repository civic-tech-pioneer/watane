## Goal

User-sim found host TECHNICAL 8.1's h2c sentence (added by S149-1) untrue of the program: h2c
prior knowledge is accepted at the protocol level, but `dispatch` (`host/src/server.rs`) reads
only the `Host` header, which an HTTP/2 request does not carry (its authority is `:authority`,
in the URI), so every h2c request gets 421 `unknown host`. Foreman decision: the program stays
as it is (serving h2c would move the Origin boundary, which this slice does not), and 8.1 says
what it does: h2c fails closed with 421 on every host; serving it is a later spec call. The red
test `regress_s149_h2c_api_status_is_served` (commit a5756ce) is turned into the pin of that
behaviour.

  `/api/status` with `:authority localhost:<port>` and asserts the response is `:status 421`
