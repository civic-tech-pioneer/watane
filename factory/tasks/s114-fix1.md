Slice: s114 — A maker previews an OpenAI-backed mod on scripted responses

## Goal

A maker changing a script can restart the preview while the previous host
finishes shutting down.

## Acceptance

1. If the previous host removes its run marker before releasing the home
   lock, the next launch waits for the lock. Restart fails neither `busy` nor
   `Database already open`.
2. Normal stop and reinstall behavior still passes the maker lifecycle test.

## Spec

dev/TECHNICAL.md §9.3–9.4 and host/TECHNICAL.md §3.

## Interface

The host home lock is `<P>/home/lock`. The CLI and script interfaces stay as
specified in s114-2.

## Files

dev/TECHNICAL.md, dev/src/preview/unix.rs, host/TECHNICAL.md, and host/src/lib.rs.

## Changed tests

None. The S114 lifecycle test caught this ordering while changing scripts
and retains its expectation that restart succeeds.

## Out of scope

Competing independent preview commands and host shutdown policy.
