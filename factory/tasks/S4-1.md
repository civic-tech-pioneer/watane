## Goal
dev can run a mod's contract tests without a server: `watane_host::Harness` installs one built mod
folder alone in a fresh temporary preview home, calls its exports as a page would, and returns each
call's value together with the events the call emitted. A call to `/call` without an `Origin`
header gets a 403 whose message says that the `Origin` header is missing.

## Acceptance
- AC1 `Harness::open(<counter fixture>, Fakes::new())` then `call("api.get", json!({}))` →
  `Outcome { value: 0, events: [] }`; `call("api.add", json!({}))` → value `1` and exactly one
  `EventRecord { interface: "mods:counter/changes@0.1.0", function: "counted", args: {"count":1} }`;
  a second `api.add` → value 2 and one event with count 2. (Compare with literals.)
- AC2 A fresh `Harness::open` of the same folder starts with empty state: `api.get` → 0, even after
  another harness counted to 2. Two harnesses of the same folder at once do not share state.
- AC3 A failed call (`api.add-then-fail`) → `Err(CallError)` with code `trap` (or the code the
  runtime gives a guest trap today; assert the literal), and the next `api.get` shows the count did
  not change. An unknown function → `Err` with code `no_function`.
- AC4 `args` accepts an object by parameter name and an array in order, as `/call` does (use an
  `echo` function with a parameter).
- AC5 Dropping the `Harness` removes its temporary home (assert the directory is gone; expose the
  path only through a `#[cfg(test)]` or `#[doc(hidden)]` accessor if the test needs it).
- AC6 Opening a folder that is not a valid mod → `Err(HostError)` (no panic); its `Display` names
  the problem.
- AC7 `POST /call` on a mod origin with no `Origin` header → 403, JSON error code `forbidden`, and
  the message contains `Origin` and the word `missing` (e.g. "the Origin header is missing; it
  must be http://counter.localhost:<port>"). A wrong `Origin` keeps a 403 whose message says it
  must match the mod origin. Update the existing tests that assert the old text.
- AC8 `cargo test`, clippy `-D warnings`, `cargo fmt --check` pass; existing tests stay green.

## Interface
Provides, fixed (task S4-3 in dev builds on exactly these, re-exported from the crate root):
```rust
pub type Fakes = BTreeMap<String, BTreeMap<String, serde_json::Value>>;
pub struct Harness { /* private */ }
impl Harness {
    pub fn open(built_mod: &Path, fakes: Fakes) -> Result<Harness, HostError>;
    /// function as watane.js names it: "api.add". Runs as Caller::Page.
    pub fn call(&self, function: &str, args: serde_json::Value) -> Result<Outcome, CallError>;
}
#[derive(Debug, Clone, PartialEq)] pub struct Outcome { pub value: serde_json::Value, pub events: Vec<EventRecord> }
#[derive(Debug, Clone, PartialEq)] pub struct EventRecord { pub interface: InterfaceName, pub function: String, pub args: serde_json::Value }
```
`InterfaceName` is pkg's type, with version. `CallError` keeps its public `code`/`message` (dev
reads `"<code>: <message>"`). `Harness` is `Send` and its `call` may run on any thread; if a call
needs the 16 MiB stack, `call` arranges it itself (dev calls it from its main thread).
`Host::call` and `call_async` keep their signatures and behaviour (pages still get events).

## Decisions already made (foreman)
- Not in S4 (write a short "S4 cut" paragraph in 15 saying so): `Harness::deliver` and
  `Harness::functions` / `FunctionInfo` (deliver needs subscriptions, which install refuses until
  links; `functions` joins with toolsets in S5). Fakes: the parameter exists and is kept in the
  harness, but no import is linked to it yet, because install still refuses mods that call other
  mods; such a mod gives `Err(HostError)` at `open`. Mark it `// ponytail: fakes link with calls (step 2)`.
- The temporary home is a new directory under `std::env::temp_dir()` with a random name
  (`getrandom` is already a dependency); `tempfile` stays a dev-dependency. Use the existing
  preview `Host::open` + folder install; do not add a second install path.
- Recording events: let the call return its outbox to the harness (e.g. a crate-private variant
  of the call that also returns the emitted `Emission`s), rather than subscribing to the bus.
  A failed call records nothing.
