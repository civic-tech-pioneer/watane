## Goal
When a mod's agents need a folder (or tools, or the ChatGPT plan), Alice sees the consent view
with the exact words of app 19.2 (`Let <mod> have agents work in <folder> (<profile>, through
<provider>)?`), while the mod's call has already returned. `Deny` keeps nothing and the next ask
shows the view again; `Approve` lets the host keep the consent. In the mod's details, a group
`Agents` lists each consent in the words of its question, with a switch that withdraws it (the
host then ends what depended on it), next to the two Claude Code grant rows in their short words.
An install whose links reach a Claude Code provider shows `Uses Claude Code through <provider>.`
This is app 19.2 in full, and S58 and S60 of app FUNCTIONAL on the real app.
