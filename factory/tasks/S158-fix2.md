## Goal

Settles adversary RISK 3 on S158 (foreman's decision). Now that resolved addresses pass
`index::local_ip`, a DNS answer the attacker controls can choose any address, so the rule also
counts as local: IPv4-compatible IPv6 `::a.b.c.d` (deprecated, RFC 4291 2.5.5.1; apply the IPv4
rule to the embedded address, and `::`/`::1` stay as they are), the IPv4-translated
`::ffff:0:a.b.c.d` form (RFC 2765; IPv4 rule on the embedded address), IPv4 multicast 224/4,
reserved 240/4 including 255.255.255.255, and IPv6 multicast ff00::/8. This is a tightening only:
nothing that was local becomes global.
