## Goal
`add_provider` (pkg TECHNICAL 4.8) names a provider's dependency folder that changes after it was
listed with the CHANGED words (`refusal::CHANGED`, "changed while the mod was read; read it
again"), at that entry: a `wit/deps/<dep>` listed as a directory that is gone when it is opened is
refused instead of copied as an empty folder (#115), and one that is a file (or anything but a
directory) when it is opened is refused with CHANGED instead of "expected a directory without
symbolic links" (#114). Today `files()` -> `directory()` turns NotFound into `Ok(None)` (an empty
map, then copied), and `refused()` turns NotADirectory into NOT_A_DIRECTORY.

## Acceptance
AC1 (#115) A provider whose `wit/deps/x` is listed as a directory and removed before it is opened:
  `add_provider` returns `ModError::Invalid` with one violation, `Rule::Path`, file `wit/deps/x`,
  message CHANGED; the consumer's `wit/deps/x` does not exist afterwards and `deps.json` is unchanged.
  Red on main.
AC2 (#114) The same, with `wit/deps/x` replaced by a regular file after the listing: one violation,
  `Rule::Path`, `wit/deps/x`, CHANGED. Red on main.
AC3 Unchanged: a `wit/deps/x` that was a link or a file *when listed* keeps today's cause
  ("symbolic link" / ignored); a consumer-side `wit`, `wit/deps` or target part that is a link or
  not a directory keeps NOT_A_DIRECTORY; an absent consumer-side `wit/deps/<dep>` is still created.
  The existing `add::tests` and `pkg/tests/it` tests pass unchanged.
AC4 Use the existing `hook` in `add.rs` or a hook at the same point for the race; no test sleeps or
  loops on a real race in the default run.
