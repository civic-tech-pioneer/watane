## Goal
dist builds stage S8 (dist/TECHNICAL.md 8 row S8, behaviour 5.12): a home opens with no identity
(`Dist::open_keyless`) and still follows, refreshes, searches, fetches and stores; every signing
path gives `NoIdentity` before it asks `confirm` or touches a file. An unused identity can be
dropped. dist gains the holder methods that `node` will wrap for net's `Holdings` (net/TECHNICAL
3.1): `heads`, `entries`, `fork`, `package_file`, `missing_packages`, `ingest` with a `Reason`,
`store_package`, `keep`, `search_stored`; kept records in `follows.json` (4.4), `ChannelView.kept`,
`Via::Kept`, `Options.max_kept`; and `confirm_own_head`. The lock rule of RV-06 holds: no holder
method takes the read mutex or the own-channel mutex, and none makes a request. `identity()` and
`fingerprint()` become `Option`; a keyed home behaves exactly as before. dist gains no thread, no
socket, no dependency, and no dependency on `net`.

  `site/`; publish then gives `NoIdentity`. With one statement: `IdentityInUse`, key file unchanged.
- AC3 (A44) `holder_*`: Bob's home holding Alice's channel: `heads`, `entries`, `fork` give the
  stored bytes; a keyless home `ingest`s them as `Kept`: stored, `follows.json` (read with
  `serde_json`) has a record with only `kept` (base `""`, bases `[]`); a refresh and an unfollow keep
  it; an entry with one changed byte is not stored. `entries` cuts at `max_bytes` (at least one
  entry when limit > 0). `package_file` of a withdrawn release is `None`.
- AC4 (A45) `max_kept` 2 and two kept: a third `Kept` ingest gives `NotWanted` and stores nothing;
  as `Asked` it is stored with no record and is absent from `heads(None)`. `keep` past the cap is
  `TooManyKept { max }`; `keep` of an unstored channel is `NotFollowed { local_only: false }`.
- AC5 (A46) keyless home holding Alice's release entry: `store_package` of the package file from
  another home, then `fetch` gives it with no request (`Fetched.link` `None`); a file with one
  changed byte gives `HashMismatch` and no `packages/<id>`; an id no live release names is
  `NotNamed`.
- AC6 (A47) a refresh blocked on a host that answers after 20 s; from another thread `heads(None)`,
  `entries` and `ingest` each return within 1 s.
- AC7 (A48) restored identity, own entries 0..=2 ingested: `confirm_own_head(2, id2)` then the next
  statement has seq 3; with another id or seq 1: `HeadNotStored`, and a statement stays

- AC8 `search_stored` finds a hit in a stored channel with no record (`via` empty, `link` `None`);

  `refresh` skips it; search over a kept record has `Via::Kept` last.
