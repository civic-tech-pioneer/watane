## Goal
`serve --json` tells the agent where its tools are: `result.mcp` is
`{"url": "http://localhost:<port>/mcp/preview", "toolset": "preview", "token": "wt_..."}`
(dev 2.4 **serve**), also on a reused preview. A `serve` refused because the tests fail tells
the agent what to run next: `next` is `watane-dev test --json`.

## Interface
Takes from S5-1 (host; fixed): the preview ready line (`watane_host::Ready`) has `mcp` =
`"http://localhost:<port>/mcp/preview"` and `token` = `Some("wt_...")`. Build the URL from the
port (as `api` is built now), not from the ready line's text; take only the token from it.
The host's MCP takes `POST` with `Authorization: Bearer <token>`, `Content-Type:
application/json`, no `Origin`, one JSON-RPC object, and answers JSON; `tools/call` results
are `{"content":[{"type":"text","text":T}],"isError":E}`.
The ignored tests run only once S5-1 is in; until then they may fail, and the run needs only
the non-ignored tests green.
