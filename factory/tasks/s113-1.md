## Goal
Alice can tell what she is declining, what interface a mod calls, and when an install from Find can follow a channel. The manager explains a busy port, shows progress during channel actions and keeps hidden views current. A grant change lets an open mod page refresh while its existing calls settle.

## Acceptance
1. Deny identifies its request. Call consent names the interface in words, with the exact grant available for inspection. Find discloses following. Remove asks before applying.
2. Follow and Add show progress while pending. A disabled provider exposes the host's message. A busy port says the local API is not running.
3. Grant changes refresh a live page in place. Hidden manager polling continues. Reinstall after keeping data preserves storage and should show it as kept when the host can attest it. Invalid fetch bodies name the offending field or object shape.
4. The Linux runner names dependency versions and sets NO_AT_BRIDGE.
