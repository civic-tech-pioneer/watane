## Goal

each mod page on its own origin `http://<local>.localhost:<port>/` with the stand-in CSP, a

## Interface
Provides (fixed, used by S10-4) in `app/tests/support/pages.rs`, included by a test with
`#[path = "support/pages.rs"] mod pages;` (S10-3 owns `tests/support/mod.rs`; do not create it):
```rust
pub struct Pages { pub port: u16, /* .. */ }      // stops on drop
impl Pages { pub fn start(dir: &Path) -> Pages; pub fn url(&self, local: &str) -> String; } // "http://<local>.localhost:<port>/"
pub struct Listener { pub port: u16, /* .. */ }   // stops on drop
impl Listener { pub fn start() -> Listener; pub fn count(&self) -> usize; }
```
Blocking API (a background thread with its own tokio runtime), so a plain `#[test]` uses it.
The hostile page reads its targets from its query string: `?listener=<port>&api=<port>`
(`api` is the port of a local API; in stage A the test passes `Pages.port`). Its report:
```json
{"done": true, "navTried": true, "storageBefore": null | "<string>",
 "attacks": [{"name": "<attack>", "outcome": "refused" | "allowed", "detail": "<text>"}]}
```
`storageBefore` is `localStorage.getItem("hostile")` read before the page writes
`localStorage.setItem("hostile", "<random>")`. `outcome` is `allowed` only when the attack got
through (a command answered, a response body was read, a window object came back, a frame
loaded); a thrown error, a rejection, a missing API or a blocked load is `refused`, with the
error text as `detail`. An attack that cannot be judged in the page (a WebSocket that never
opens) is `refused`; the listener's count is the oracle for those.
