## Goal
dev build stage 7 (`dev/TECHNICAL.md` 16): `watane-dev publish [--no-source] [--home <path>]
[--wait <seconds>]`. It refuses a mod that depends on a local provider before anything else,
checks that the home host with the app runs (as `install` does), tests the mod, packs it (with
source unless `--no-source`), posts the package bytes to `/api/publish` and reports the app's
answer plus the package id and whether the source went along. A decline, a timeout or a missing
app comes back with a fix and a `next`, as `install` does.

## Interface
Takes from app (exists, do not change app): `POST /api/publish` with the package bytes
(`application/octet-stream`) on the home host's port → 200 `{"release", "site", "link": string|null}`;
403 `{"error":{"code":"refused",..}}` on a no; 400/409/413/422 `{"error":{"code","message"}}`.
Takes from pkg as is: `watane_pkg::{pack, Package}`.
