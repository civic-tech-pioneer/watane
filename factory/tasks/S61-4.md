## Goal
dist's `identity()` and `fingerprint()` are now `Option` and dist has a `NoIdentity` error (S61-2).
The app still opens every home with `Dist::open`, so it always has an identity: every function
works exactly as before (J2 to J5 green). Where the app reads the identity it now reads the
`Option`; where it has none it answers with dist's `NoIdentity` instead of panicking: a local API
route gives 409 `no_identity` (app/TECHNICAL 8), a command gives `bad_input` with dist's
`NoIdentity` text (9.8 "A replica"), and `Status.identity` is `null`. No new view, no `node`, no
replica text: that is stage G.
