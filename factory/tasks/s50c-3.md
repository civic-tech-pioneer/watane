## Goal
The clean-Mac test exists in two parts. `install/tests/clean_mac.sh` runs inside a Mac (the
guest VM, or the release runner with `--fresh-home`): asserts the machine is clean (12.4),
installs from a release (the real one over `curl`, or `--from <dir>` with `file://`), and
checks INST-S-1, 2, 3, 15, 16, 23, 24, 25 and the `xcode-select --install` line. 
`install/tests/vm_mac.sh` runs on the host Mac and drives a Tart VM (clone, run headless, ssh,
delete) to run `clean_mac.sh` in a fresh guest, once without and once with the command line
tools. Tart is not installed on this Mac yet: build and check everything that does not need
it; the foreman runs the VM part when the human approves Tart.

## Acceptance
- AC1 `clean_mac.sh [--from <dir>] [--fresh-home | --part clean | --part clt]` does exactly
  the steps of install/TECHNICAL 12.3 and the assertions of 12.4, POSIX `sh`, stock macOS
  tools only (`plutil` for JSON and plists, `script(1)` for answers on a pseudo-terminal, as
  12.1 does), every command under `env -i HOME="$H" PATH=/usr/bin:/bin:/usr/sbin:/sbin
  TERM=dumb`; last line `CLEAN-MAC PASS` and exit 0, or the first failed assertion with its
  command and exit 1. Without `--from` it installs with the one-line command of 3.1.
- AC2 `--fresh-home` really runs on this Mac: build the three programs and the app the way
  release.yml will (`cargo build --release --locked -p watane-host -p watane-dev -p
  watane-node`; the app per 7.3, or if `cargo tauri` is not installed here, a fake app bundle
  is NOT acceptable: install `tauri-cli` with the exact version s50c-2 picks, read from
  `Cargo.lock`'s tauri version), pack with `install/package.sh aarch64-apple-darwin 0.1.0
  <dir>`, then `sh install/tests/clean_mac.sh --from <dir> --fresh-home` prints `CLEAN-MAC
  PASS`. Note: this Mac has cargo in `~/.cargo`, Homebrew and a checkout; the 12.4 assertions
  must still pass because `--fresh-home` uses a fresh `H` and the `env -i` PATH. Put the
  exact commands and output tail in your last message.
- AC3 A test `install/tests/clean_mac.rs` (`#[ignore = "slow: needs a release build"]` is fine
  for a full run) checks, without a VM: `sh -n` of both scripts; shellcheck of both when
  installed; `clean_mac.sh` refuses a non-clean environment (a `cargo` on its PATH via a temp
  `HOME` holding `.cargo`, a `Cargo.toml` above `H`), printing the 12.4 failure line and exit
  1, before any install. The fast part runs in `cargo test`.
- AC4 `vm_mac.sh [--prepare] [--from <dir>]` follows 12.3 (Tart: `tart clone`, `tart run
  --no-graphics &`, `tart ip --wait`, ssh/scp as `admin` via `SSH_ASKPASS` with a 600 s
  deadline, `ssh -tt`, a trap that `tart stop` + `tart delete` the run's VM on every exit;
  `--prepare` makes `watane-clean` and `watane-clean-clt` from
  `ghcr.io/cirruslabs/macos-golden-gate-vanilla:latest`), prints `VM PASS` or the first
  failure. When `tart` is missing it exits 2 with `vm_mac.sh: tart is not installed (see
  install/TECHNICAL.md 12.3)` and touches nothing; test that in `clean_mac.rs`. Check the Tart
  CLI flags against `https://github.com/openai/tart` docs (`gh api`), do not install Tart.
- AC5 Every other test of `watane-install` passes; clippy, fmt clean.
