## Goal
Find and Updates look and work as the human's design draws them, in light and dark, on the tokens
and classes S84-3 built: one search box that reads publisher and interface words, index chips with a
drop button, result cards with their install state and the compromised block; Updates as three
sections of cards (Needs you, Channels, Updated by itself) with Not now / Review…, and Checked /
Check now with `Checking…` while it runs.

## Design
Read the boards for layout, sizes, colours and words, never as code to copy:
`spec/design/manager/Find.dc.html`, `Updates.dc.html`, `canvas.json` (design rules). The PNGs in
`render/` are older: where they differ, the `.dc.html` wins. app/TECHNICAL 5.3.5/5.3.6 say where a
rule wins over a board (drop button on chips, followed channels in Find, whole failure causes); follow
the spec there.
