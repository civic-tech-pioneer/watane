## Goal

This task closes the adversary's round-8 breach (7590bee). `read_link` of a link for a channel with no record
reads the link's base as a listed read and returns it as `Fetched.link`, but never notes it in `seen`. The app
calls `read_link` for a manager mod's install (`read_managed_release`), then `follow_fetched` follows
`Fetched.link` (DD-29): the follow finds no record, no tombstone, gives the base, and its later redirects reach
the local network. Foreman decision: a link a mod hands to `read_link` is a derived link (DD-48, option A), not
one the participant gave. `read_link` is never the path of a pasted link (that is `follow` / `open_link`).
Rule: before its first request, `read_link` notes the link's base with `note_provider_base` (s105-fix7), as
`fetch_from_providers` does, so a later link at that base is a listed first read and gives nothing. A failed
save fails the call with no request.
