## Goal
dist build stage S3 (`dist/TECHNICAL.md` 8): Alice publishes the reading list's package. dist
checks the package and makes its release body with `pkg`, asks the app once, signs, keeps the
verified package, and writes her site folder (`head`, `entries/<seq>`, `packages/<id>`) next to
any foreign files; a folder that holds another channel is refused by name. With a site URL set,
`own_link` gives the link Bob will open.

## Acceptance
- AC1 (A2, `own_refuse_publish`) refuse: `Refused`; no own head (second `Log::open`), no file
  in `site_dir()` and no `<home>/dist/packages/<id>`.
- AC2 (A3, `own_request_publish`) approve: the recorded `Statement::Release.release` equals
  `Release::decode` of the stored body; its `reference` names Alice's key, slug `reading-list`
  and the version; `size` and the source flag match the package.
- AC3 (A4) a second package with the same slug and version: `VersionExists` before `confirm`.
- AC4 (A5) the `recommendations` fixture (local provider `reading-list`, copy it from
  `pkg/tests/fixtures/`): `UnreleasedProvider { provider: reading-list }` before `confirm`.
- AC5 `PackageTooLarge` for bytes above `max_package`, before parsing.
- AC6 (A6, `site_*`) two releases, one withdrawn (withdraw is approved through the real path):
  `site_dir()` holds exactly `head`, `entries/0..2`, and the one package not withdrawn; each
  entry file equals `Entry::bytes` from `Log::entries`, `head` equals the last one, the package
  file's name is the `blake3` hex of its bytes.
- AC7 (A7) `export(dir)` into a folder with `index.html` and `CNAME` leaves both unchanged.
- AC8 (A8) `export(dir)` into a folder holding Carol's channel (another home's site) gives
  `ExportConflict` naming `head`; Carol's files are unchanged.
- AC9 (A9) `set_site_url` then `own_link(Some(slug))`: the text parses back to Alice's key, the
  normalized URL and the slug; without a site URL, `own_link` is `NoSiteUrl` and `Published.link`
  is `None`.
- AC10 an export writes nothing when every file is already equal (no mtime change).
- AC11 `cargo test -p watane-dist`, clippy `--all-targets -D warnings`, `cargo fmt --check` pass.
