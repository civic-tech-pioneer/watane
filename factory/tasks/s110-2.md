Depends on: none
Slice: S110 — CI is green on Windows, so its check can be required.

## Goal

Open and create the same identity key format on Windows using Win32 file
handles and an owner-only access control list. Refuse a reparse point, a
nonregular or multiply linked file, a foreign owner or an exposed key
before reading any seed bytes. Serialize first creation and restore.

## Acceptance

1. AC1. Windows creates the private key and reopens the same identity.
2. AC2. Windows refuses a reparse point and leaves its target intact.
3. AC3. Windows refuses a key whose ACL grants access to another principal.
4. AC4. Windows does not write seed bytes when it cannot establish access
   control.
5. AC5. Unix keeps its existing checks and error behavior.
6. AC6. Windows refuses an identity drop when it cannot flush the deletion.
