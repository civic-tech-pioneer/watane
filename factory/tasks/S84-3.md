## Goal
The manager's Library looks and works as the human's design draws it, in light and dark: tokens and
type, the header with tabs and one Add mod popover, the tile grid with monograms and badges in the
order main, Problem, Update, A–Z, the details side panel (grant switches, start row, connections,
inline confirm, technical details), the first-start view, the Installed note, and the drop target.
Settings keeps its controls in the new tokens. Find and Updates keep working in their old layout
(S84-4 restyles them) but with the ids 5.3.7 renames.

## Design
Read the boards for layout, sizes, colours and words, never as code to copy:
`spec/design/manager/Main.dc.html` (Library and details), `Empty.dc.html` (first start and, via its
Tweaks, the drop state), `Installed.dc.html` (the note after an install, new), `canvas.json` (design
rules). The PNGs in `render/` are older: where they differ, the `.dc.html` wins. app/TECHNICAL 5.3
says where a rule wins over a board; follow 5.3, not the board, there.
