## Goal
Three log errors are vague. `Log::open` on a path that is a regular file says "is not a regular
file or directory"; it should say "is not a directory". `Log::open("")` says ": empty path" (the
`Io` Display with an empty path); it should name the empty path. "bad backup: length" does not
say that 108 bytes are expected or how many came.

Decided here (not by you):
- `Error::NotPlain { path }` becomes `NotPlain { path: PathBuf, expected: &'static str }` with
  Display `{path} is not a {expected} (a symbolic link is refused)`; `expected` is `"directory"`
  for the log directory and `"regular file"` for `identity.key` (and any other file check).
- New variant `Error::EmptyPath`, Display `the log directory path is empty`. `Log::open("")`
  returns it (replaces 3.x step 1 "`Io` with `InvalidInput`").
- `Error::BadBackup(&'static str)` becomes `BadBackup { field: &'static str, expected: String,
  found: String }`, Display `bad backup: {field}: expected {expected}, found {found}`. Length:
  `expected 108 bytes, found 107 bytes`. Magic: `expected "watanek1"`, found the 8 bytes
  escaped (`{:?}` of the lossy string is fine). Memory / passes / lanes: expected the bound from
  4.9 (`8192 to 1048576 KiB and at least 8 x lanes`, `1 to 10`, `1 to 16`), found the number.
  `field` keeps today's values.
- No other crate matches these variants (searched app, host, dist, dev); no change is needed there.

## Acceptance
Tests at the lowest level: `log/tests/backup.rs` and a new `log/tests/open_errors.rs`.
- AC1 `Log::open(f)` where `f` is a regular file → `Err(NotPlain { expected: "directory", .. })`,
  `to_string()` = `<f> is not a directory (a symbolic link is refused)`.
- AC2 A directory symlink as the log directory → `NotPlain { expected: "directory" }`; a
  directory at `dir/identity.key` → `NotPlain { expected: "regular file" }`.
- AC3 `Log::open(Path::new(""))` → `Err(EmptyPath)`, `to_string()` = `the log directory path is
  empty`.
- AC4 Restoring 107 bytes → `BadBackup { field: "length", .. }`, `to_string()` = `bad backup:
  length: expected 108 bytes, found 107 bytes`; 109 bytes → `found 109 bytes`.
- AC5 Magic, memory, passes, lanes keep their `field` and are still refused before Argon2id runs
  (the existing < 50 ms check); each message contains `expected` and the bad value.
- AC6 All log tests pass (`cargo test -p watane-log -- --include-ignored`); dist still builds
  and its tests pass (`cargo test -p watane-dist`).
