## Goal

Discover the Windows Rust tools by their executable names. Keep the
preview process-group safety requirement. On Windows, refuse preview
start and stop before any build or process operation when the Unix
process-group lifecycle cannot be provided.

## Acceptance

1. AC1. Windows discovers Rust tools through their native executable names.
2. AC2. Windows preview start and stop report a process-group diagnostic
   through the normal CLI envelope.
3. AC3. Unix preview operation and coverage remain available.
