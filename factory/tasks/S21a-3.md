Slice: S21a — Alice publishes, Bob follows (dist).

## Goal
dist build stages S4 and S5 (`dist/TECHNICAL.md` 8): Bob opens Alice's link, follows her
channel over plain HTTP, and gets the same package, verified (every entry decoded and checked
against the link's key and the file's seq; the package by BLAKE3 and by `pkg`'s
`Release::check`). A changed file on the host is refused and the error names the cause and the
URL. Refresh reports new releases and withdrawals, stops at a fork, shows a host that rolls
back. Alice's backup restores her identity in a new home; that home signs nothing until it
reads her channel from her link and calls `log.confirm_own_head`, then her next statement
continues her chain. `j3_dist` runs the dist half of J3 end to end.

## Acceptance
- AC1 (A10, `follow_*`) Bob's `open_link(alice_link)` follows Alice and returns `Fetched`
  whose package bytes equal Alice's package and whose entry equals Alice's stored release entry.
- AC2 (A11) one byte of `packages/<id>` changed on the host: `fetch` is `HashMismatch` with
  the URL; `<bob>/dist/packages/` holds no file for it.
- AC3 (A12) one byte of `entries/1` changed: `follow` fails with `Invalid` naming
  `entries/1`'s URL; Bob holds no entry above seq 0 and follows nothing.
- AC4 (A13) the host serves Carol's channel at Alice's URL: `WrongChannel`; follows nothing.
- AC5 (DIST-F-30) following one's own link is `OwnChannel`.
- AC6 (A14, `refresh_*`) Alice publishes 1.1.0 and withdraws 1.0.0 (reason "bug"); Bob's
  refresh reports exactly `Change::Release(1.1.0)` then `Change::Withdrawn(1.0.0, "bug")`.
- AC7 (A15) the fork of TECHNICAL 7 (made with `watane_log` only): refresh gives
  `Outcome::Compromised`; `fetch` of any Alice release is `Compromised`; a further refresh
  makes zero requests (`TestHost` request count).
- AC8 (A16) host serves the older state: `Outcome::Behind`; Bob still holds the newer head.
- AC9 (A17) package one byte above the limit: `TooLarge` with URL; `Stall` beyond
  `package_timeout`: `Timeout` with URL (wide margins; not a timing test).
- AC10 (A18) after one fetch, stop the host: a second `fetch` succeeds with no request.
- AC11 (A19, `restore_*`) new home restores Alice's backup: `publish` is `OwnHeadUnconfirmed`
  and `confirm` was never called; `confirm_own(Some(carol_link))` is `WrongChannel` and the
  head stays unconfirmed; `confirm_own(Some(alice_link))` ingests her channel, calls
  `log.confirm_own_head`, and the next publish gets seq = her published head + 1; Bob's
  refresh stores it with `Status::Ok`.
- AC12 (`j3_dist`) open, set name, publish, set site URL to the `TestHost` URL, link, Bob
  `open_link` (verified package), then tamper one package byte in a fresh copy and a fresh Bob:
  refused, and the error's `Display` names the cause (hash mismatch) and the URL.
- AC13 `fetch` of a `ReleaseRef` parsed from literal text works.
- AC14 `cargo test -p watane-dist` (whole default run under 2 min), clippy
  `--all-targets -D warnings`, `cargo fmt --check` pass.
