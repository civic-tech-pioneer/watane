subscriber, with the hop and delivery limits. In a contract harness, a call import answers from
the file's fakes, and `deliver` runs a subscription export. The `install refuses links` cut and both
`ponytail:` comments (`bus.rs`, `harness.rs`) go away.

## Interface
Provides (fixed; dev S11-4 builds on it before you finish):
- `pub enum Caller { Page, Agent(Handle), Mod(LocalName) }`; `who()` gives `mod:<local>`.
- `Harness::deliver(&self, function: &str, args: Value) -> Result<Outcome, CallError>`.
  `function` is `<short iface>.<fn>` where `<short iface>` is `InterfaceName::interface()` of an
  entry of `world().subscriptions`. The caller is `Caller::Mod(<provider slug as LocalName>)`.
  Same commit, rollback and event-record rules as `call`. Add it to 2.6.
- `Fakes` keys stay as 2.6 (`mods:<slug>/<iface>` without version). A fake's JSON is converted to
  the import's result type (6.9); a conversion mismatch is `trap` naming the function.
- `Host::install_folders(&[PathBuf], port)` keeps its signature; it now takes a set of folders in
  any order and installs providers first. Errors use the codes of 2.2: `missing_providers`,
  `cycle`, `ambiguous_provider`.
- In a preview, every declared `Call` and `Subscribe` grant is granted (no revoke yet).
