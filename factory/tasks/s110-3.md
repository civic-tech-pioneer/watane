Subsystem: net
Effort: medium
Depends on: s110-2
Slice: S110 — CI is green on Windows, so its check can be required.

## Goal

Open a net home on Windows and store its node key, pairing records and
blob staging files with the private file protections used for log.

## Acceptance

1. AC1. A fresh net home on Windows has a private key and reopens with
   the same node key. An exposed node key refuses to open.
2. AC2. Pairing files reopen and retain their private ACLs on Windows.
3. AC3. Blob storage and staging use private directories and files on
   Windows. Unix behavior stays consistent with the existing tests.

## Spec

- `net/TECHNICAL.md` sections 4.5 and 5.6
- `log/TECHNICAL.md` section 4.7
- `spec/TECHNICAL.md` section 6, Node

## Interface

Use the Windows file helper from s110-2. Its path operations take `&Path`
and return `std::io::Result`. No changes to `Net::open`.

## Files

`net/`, the private Windows file helper in `log/windows-fs/`, and workspace
dependency metadata.

## Changed tests

`keyfile` keeps Unix mode and symlink coverage. The node fixture that
counts `/dev/fd` sockets runs on Unix. The pairing storage test checks
Unix modes or Windows DACLs and keeps its existing reopen assertions.

## Out of scope

Changes to the QUIC protocol and the GitHub ruleset.
