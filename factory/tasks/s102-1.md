Slice: S102 — Alice connects her agent accounts in Settings

## Goal
Alice can sign in with and sign out of ChatGPT, and choose or clear the Claude Code program in Settings. The registered client remains Q12.

## Acceptance
1. S54: A driver issuer and browser complete the authorization-code flow. Settings shows the verified plan and status exposes no tokens.
2. S57: Sign out removes the private account file and returns Settings to Not signed in.
3. S61: A stand-in reporting 2.1.294 is refused with the specified words and an existing choice survives. A stand-in reporting 2.1.295 is stored and shown by path and version.
4. The callback accepts only its per-attempt path and one matching request, uses a five-minute deadline, and the app reports unavailable for a concurrent sign-in.
5. The account file is private and atomically replaced. Failed token checks write nothing.

## Interface
No sibling interface. Main-only commands chatgpt_sign_in -> {plan}, chatgpt_sign_out -> null, claude_binary_pick -> {path, version} or null, and claude_binary_clear -> null. Status fields are chatgpt {signedIn, plan, error} and claude {path, version} or null.
