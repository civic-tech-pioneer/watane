## Goal
Detect whether the scripted server remains reachable after drop on the CI runners.

## Acceptance
1. A live listener accepts a TCP connection on each address.
2. After drop, neither address accepts a TCP connection. Windows can time out a probe to a closed loopback port.
3. Windows CI passes the listener shutdown test.
