## Goal
A mod (the collector) that calls a collect function of its own outlet gets back the joined lists
answered by each enabled, granted subscriber, in local-name order, without learning who answered.
A failed answer is left out and logged; only a time or fuel limit fails the collector. The plan
counts a collect subscription as a cycle edge from collector to subscriber. In a `Harness`, a
collect returns its fake, or `[]` (host stage 10).

## Interface
Takes (fixed): `watane_pkg::World::collects: Vec<InterfaceName>` (sorted subset of `events`).
Provides (fixed; dev task S65-3 uses it): no new public API. `watane_host::Fakes` unchanged in
type; a key `mods:<own slug>/<outlet>` (no version) fakes the collects of the mod under test, value
function → the whole joined JSON list. `Harness::deliver` of a collect function returns the mod's
own answer in `Outcome.value`.
