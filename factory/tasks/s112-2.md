## Goal

The log refuses a log directory that another user owns, so root running watane
over a 0700 folder someone else owns never writes its key there (S109 review).
On Windows the equivalent refuses (another user's directory, lock or key is
`Io` PermissionDenied at the path) or is named a known limit.

## Acceptance

1. AC1. `Log::open` and `Log::open_keyless` on a private directory owned by
   another UID are `Error::DirectoryOwner { path, owner, current }`; nothing is
   created in it.
2. AC2. The owner is checked on the opened directory handle in `lock_dir`, so
   `replace` and `remove` refuse too (r1, F1.2: a test pins it as root).
3. AC3. On Windows, a directory with a different owner SID is refused, with a
   test that runs on Windows CI; the identity key test reads its ACL without a
   PowerShell module.
