## Goal
With net's hint fix (S72-1), node's three-machine tests no longer need their reconnect workaround:
Alice's light laptop gets each update through the server within seconds, never waiting for the
10-minute sync.

## Acceptance
- AC1 node/tests/light.rs: `keeps` waits for the server to hold entry and package with one bounded
  wait and no `reconnect`; S7's 0.2.0 offer is one bounded wait with no `reconnect`; `reconnect`
  and the workaround comments are gone. Any other `set_options` toggling that existed only as a
  workaround goes too (one that tests behaviour, like turning the laptop off in S6, stays).
- AC2 `cargo test -p watane-node --test light` passes 20 of 20 runs in a row (a shell loop; report
  the count and any failure verbatim). If a run fails, do not add the workaround back: report it.
- AC3 `cargo test -p watane-node` passes; time near ~15 s plus whatever S72-2 added; clippy and fmt
  clean. node/TECHNICAL.md 12's net row says the workaround is removed.
