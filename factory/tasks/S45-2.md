## Goal
When Eve's dist cannot find a base for a provider's channel, the error says why and what to do:
if the only listings that name a base were skipped because they point at a local address, it says
so instead of "no listing names a base"; either way the message ends with the step that settles it
(follow the publisher's link). Provider hint bases are read only until the first (most trusted)
one serves, so a fetch stops contacting further hosts. On a fetch with no record whose package is
already cached, `Fetched.link` is the first base in trust order, as on every other cache hit. The
`fetch.rs` ac9 test's TooLarge step uses the normal test timeout; only its stall step keeps 300 ms.

## Interface
`DistError::NotFollowed { channel: PublicKey, local_only: bool }` (was `{ channel }`).
`local_only` is true only in 5.11 step 4 when at least one live listing named a base for the
channel and every such base was skipped as a local address; every other construction (unfollow,
refresh of a channel with no record, `fetch_package` with no base) sets `false`. No other crate
names the variant (checked: app, host, dev).
