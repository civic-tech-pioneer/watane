Slice: S12b — The agent installs a mod into Alice's home.

## Goal
A maker's coding agent runs `watane-dev install --json` in a mod folder. dev tests the mod and its
local providers (as `serve` does), asks the home host of Alice's app to install them, waits for
Alice's answer, and reports it: the installed mods with their pages, or that Alice said no, or that
no app runs (with a fix that says to start the app). A fake home host, the program `fake-watane`,
lets tests and a person try this without the app.

## Interface
Takes from host (exists, do not change host): `GET /api/status` →
`{"watane":1,"mode":"home"|"preview","home":"<path>","port":n,"app":bool}`; `POST /api/install`
`{"folders":[abs...]}` → `{"installed":[InstalledMod]}` or `{"error":{"code","message"}}`, code
`refused` when the participant says no; `watane_host::{default_home, RunInfo}`.
Sibling task S12b-2 (dev, parallel) edits `cli.rs` only in the `Add` path and `check.rs`/`deps.rs`;
keep your `cli.rs` change to the new `Install` command.
