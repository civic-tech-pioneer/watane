Slice: S141 — Make preview setup and disabled installs understandable
## Goal
Give makers an actionable scripted judge setup hint and make disabled installs visible on rerun.
## Acceptance
1. A configured judge without an HTTP grant tells the maker which manifest host and WIT import to add. A manifest with hosts but no HTTP import reports both choices and its `serve` rerun retains the explicit `--script`.
2. The contract fakes table names `watane:host/timers` and its default `firing-origin` read.
3. Reusing a preview with a disabled install reports the condition without deleting preview data or silently lifting the disable.
## Spec
dev TECHNICAL §8.1, §9.3, §18.4; host TECHNICAL §19.6; S141 in factory/PLAN.md.
## Interface
Use the existing installed-mod reply and `serve` envelope. No new endpoint, CLI option or WIT.
## Files
dev/src/preview/unix.rs, dev/TECHNICAL.md, factory/tasks/S141-3.md.
## Changed tests
`scripted_preview::serve_binds_only_a_scripted_judge_with_plays` matches the existing warning prefix through the rerun. Update that assertion to also require the WIT import. Add coverage for the missing import and disabled install at the nearest entry point.
## Out of scope
Changing the manager's privileges, editing preview state on disk, and deciding a public API for enabling a disabled mod.
