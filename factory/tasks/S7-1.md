Subsystem: pkg
Effort: high
Slice: S7 — Pack a mod: a mod folder packs into one package and unpacks to the same folder.

## Goal
`pkg` stage 5 exists (`pkg/src/package.rs`). `pack(dir, include_source)` turns a mod folder into one
canonical byte string (`Package`) whose `PackageId` depends only on the files' paths and bytes: no
times, modes, hidden files or build output. `Package::from_bytes` decodes untrusted bytes without
trusting any declared length, and `Package::unpack` writes a package to a new folder and refuses
every hostile form: traversal, links, oversize, duplicate or case-clashing paths. The host and dev
will later use it to install and to preview; this task builds only pkg.

## Acceptance
- AC1 `pack_golden` (A11): the folder of 6.5 (write it in a temp dir from the literals), packed
  without source, gives exactly the 159 bytes of the 6.5 hex and id
  `0866e9df433265eaf0d959c589d82f1c2020d5b07faf7a530b012ec9f62ff87b`.
- AC2 `pack_determinism` (A12): two copies of one folder made with files created in different
  order, different mtimes and modes, pack to equal bytes and equal `id()`.
- AC3 `pack_content` (A13, A14): a folder with `.git/`, `logic/target/`, `.DS_Store`, `notes.md` and
  `logic/src/lib.rs`: `paths()` without source and with source equal literal lists (with source adds
  only the source paths of 6.1 that exist). A link `ui/key` to a file outside the folder:
  `PackageError::Symlink` naming `ui/key`. A file `ui/a b.js`: `PackageError::Path` naming it. A
  FIFO under `ui/`: refused (not read, no hang).
- AC4 `decode_refusals` (A15, A16): bytes built in the test by a raw writer that neither sorts nor
  checks; each of these is refused by `from_bytes` with the path named where there is one: paths
  `ui/../../x`, `/x`, `ui//x`, `ui/.x`; both `ui/A.js` and `ui/a.js`; a path that is also the parent
  of another (`ui/x` and `ui/x/y`); a path outside 6.1 (e.g. `notes.md`); length 64 MiB + 1
  (`TooLarge`, checked before anything else); a record whose `size` passes the end of the input; bad
  magic; format `02`; count 0; count > 4096; unsorted; duplicate; one trailing byte; a short record.
  None panics.
- AC5 `unpack`: a package unpacked to a new folder gives files equal to a literal map (directory
  walk), files 0644 and directories 0755; the returned `Mod` reads the folder. A17: dest exists →
  `DestExists`, existing folder unchanged. A18: a package whose `mod.toml` breaks a rule →
  `PackageError::Mod(ModError::Invalid(..))` with rule `mod-toml`, and dest does not exist afterwards.
  Parent of dest missing → error, nothing written.
- AC6 `round_trip`: 200 file sets from a seeded generator (no new dependency: a small LCG or
  similar in the test) under `ui/` of a valid page-only mod: `pack` then `from_bytes(as_bytes)` gives
  back each file (`file(path)`), and `unpack` gives back the same tree.
- AC7 The fixture `pkg/tests/fixtures/hello` (and the other valid page-only fixtures) pack twice to
  equal bytes; `PackageId::of(p.as_bytes()) == p.id()`; `len()` equals the byte length;
  `has_source()` true only when a source path is present.
- AC8 `cargo test`, `cargo clippy --all-targets -- -D warnings`, `cargo fmt --check` green in pkg;
  existing tests stay green. No new dependency.

## Interface
Provides, fixed (host, dev and dist build against it): exactly the `package.rs` block of section 8:
`MAX_PACKAGE_BYTES: u64 = 67_108_864`, `pack(&Path, bool) -> Result<Package, PackageError>`,
`Package` (`from_bytes`, `id`, `as_bytes`, `into_bytes`, `len`, `paths`, `file`, `has_source`,
`unpack`), `PackageError` with its variants and messages. All re-exported at the crate root.
`PackageId::of` already exists in `names.rs`; keep it. `Package` is `Send + Sync`.
