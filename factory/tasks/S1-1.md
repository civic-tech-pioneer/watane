Subsystem: pkg
Effort: high
Slice: S1 — Hello page: a coding agent runs `watane-dev new hello`, then `watane-dev serve --json`, opens `result.pages[0].url` and sees the template page.

## Goal
The crate `watane-pkg` exists and reads a mod folder. `host` and `dev` call `Mod::read(dir)` on a
page-only mod (`mod.toml`, `wit/world.wit` with an empty world, `ui/index.html`) and get its slug,
version, name, summary, world, parts and grants; a broken folder gives every `Violation` with its
`rule` and `file`. This is build stages 1 to 3 of `pkg/TECHNICAL.md` section 12, complete (not
only the page-only path): later slices add logic parts on top without reopening these files.

## Acceptance
- AC1 Stage 1 done: the `names`, `zbase32` and `compatible` tests of section 11 pass (every
  grammar of section 3 and 3.1, the version table of 5.2), each oracle a literal from the spec.
- AC2 Stage 2 done: the `mod_toml` and `deps_json` tests pass (schema, limits, unknown keys, the
  `slug`/`version` message of 4.2, canonical `Deps::write` text including `{}\n`).
- AC3 Stage 3 done: the `grants` and `rules` tests pass: one fixture under `tests/fixtures/` for
  each line of the 4.7 table (rule `component` excluded), checking `rule` and `file`; grant order and
  JSON forms of 5.1 as literals.
- AC4 A page-only folder (fixture `tests/fixtures/hello/`: `mod.toml` with name and summary,
  `wit/world.wit` = `package mods:hello@0.1.0;` + `world hello {}`, `ui/index.html`, `ui/app.js`)
  reads with `Mod::read`: slug `hello`, version `0.1.0`, `page()` = `Some(<dir>/ui)`, `logic()` =
  `None`, `grants()` empty, every list of `world()` empty, `storage` and `http` false.
- AC5 The fixture `empty` (mod.toml and an empty world, no `ui/`, no logic) is rule `parts`;
  `ui/` without `ui/index.html` is rule `parts`.
- AC6 `cargo test`, `cargo clippy --all-targets -- -D warnings` and `cargo fmt --check` pass.

## Spec
`pkg/TECHNICAL.md` sections 1 to 5 (4.8 and 4.9 excluded), 8 (the items of names, grant, meta,
deps, world, folder), 11 (the tests named above), 12 stages 1 to 3. `pkg/FUNCTIONAL.md` for A1 to A8.

## Interface
Provides exactly the signatures of `pkg/TECHNICAL.md` section 8 for: `Slug`, `Version`, `compatible`,
`InterfaceName`, `HttpHost`, `PublisherKey`, `PackageId` (`of` uses blake3), `ReleaseRef`,
`NameError`, `Provider`, `Grant` (with `Display` and `same_authority`), `Requirement`, `Mod` (`read`
and every accessor; `check_component` is NOT built), `World`, `Deps`, `ModError`, `Violation`,
`Rule`. All re-exported at the crate root. `host` (task S1-2) and `dev` (task S1-3) build against them.

## Files
`pkg/Cargo.toml`, `pkg/Cargo.lock`, `pkg/.gitignore`, `pkg/src/{lib,names,grant,meta,deps,world,folder}.rs`,
`pkg/tests/**`. Specs of any folder when wrong (record it as `pkg/AGENTS.md` says).
Dependencies: those of section 2 that these stages need (`wit-parser`, `blake3`, `data-encoding`,
`serde`, `serde_json`, `toml`, `thiserror`; dev `tempfile`). Not `minicbor`, not `wit-component`.

## Out of scope
`check_component` (stage 4), `pack`/`Package` (stage 5), `add_provider` (stage 6), `Release`
(stage 7). Do not create `component.rs`, `package.rs`, `release.rs`.
