## Goal
`watane-dev new` writes the counter template of dev TECHNICAL 4 (a logic part in Rust, a page that
calls it), without `tests/`. `check` applies the builder rules of 5.2 and 5.3. `serve` runs check,
then builds `logic.wasm` offline from the vendored crate allowlist that ships with dev (dev stage 2:
allowlist, `scripts/vendor.sh`, toolchain, builder), then starts or reuses the preview and installs
the mod as in S1. A build error comes back as `build.compile` with the file and line in the mod.
