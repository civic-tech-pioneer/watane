Slice: S2 — The page calls its logic: a coding agent runs `watane-dev new hello` and `serve --json`; Alice opens the page, clicks its button, and sees the count go up.

## Goal
`Mod::check_component` exists (pkg stage 4). Given a mod folder with a built `logic.wasm`, it says
whether that file is a WebAssembly component whose imports are only what `wit/world.wit` declares
(plus base WASI) and whose exports are exactly the world's exports. The host calls it before it
installs a logic part, and dev calls it after each build. A mod with no logic part passes.

## Acceptance
- AC1 A page-only mod (no logic part): `check_component()` is `Ok(())`.
- AC2 A mod whose world imports `watane:host/state@0.1.0` and an own-package interface
  (`import changes;`), and exports `api`, with a `logic.wasm` made by `wit-component` from that
  world (`dummy_module` + `ComponentEncoder`): `Ok(())`.
- AC3 `logic.wasm` larger than 64 MiB (sparse file is fine), a directory named `logic.wasm`, and a
  plain core module or random bytes: each is `Err(ModError::Invalid(v))` with one violation of
  rule `component`, file `logic.wasm`, message "logic.wasm is not a WebAssembly component" (size:
  a message naming the 64 MiB limit; directory: one naming that it is not a regular file).
- AC4 A component that imports an interface the world does not declare (e.g. built from a world
  with an extra `import mods:other/x@0.1.0;` or a function import): one violation, rule
  `component`, message ``logic.wasm imports `<name>`, which wit/world.wit does not declare``.
  A component that imports `wasi:random/random@0.2.x` or `wasi:cli/*@0.2.x` passes.
- AC5 Export differences: a component built from a world with one export fewer and one more than
  `wit/world.wit` gives exactly two violations, one naming each interface.
- AC6 Malformed input never panics: `decode` runs inside `catch_unwind`; a truncated component
  is a violation, not a panic.
- AC7 `cargo test`, `cargo clippy --all-targets -- -D warnings`, `cargo fmt --check` pass (from `pkg/`).

## Interface
Provides, fixed (host task S2-2 and dev task S2-4 call it):
`impl Mod { pub fn check_component(&self) -> Result<(), ModError> }`. Violations use
`Rule::Component`, `file = "logic.wasm"`. No `wit-parser` type in the public API.

`pkg/tests/component.rs`, `pkg/tests/fixtures/**` if a fixture folder helps. `pkg/TECHNICAL.md`
when wrong.
