## Goal

Repeating an installed managed release leaves publisher subscriptions alone.
Find reports a declined install using the host's typed refusal.

## Acceptance

1. Reapprove only the read of an unfollowed publisher's already installed
   release. The manager request succeeds without install consent or following.
   Run the regression red before changing the install path.
2. An interactive refusal produces the existing decline message. Consent
   omits follow copy for followed and own publishers, program and background
   requests.
3. A mismatched slug at Alice's real base is ignored by a separate reader.
   The Find listing fixture initializes its home in process.
