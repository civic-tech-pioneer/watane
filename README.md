# watane (working name)

An empty host that people fill with their own mods.

Licensed under either of [MIT](LICENSE-MIT) or [Apache-2.0](LICENSE-APACHE), at your option.

## Install (macOS, Apple silicon)

On macOS 14 or later:

```sh
curl -fsSL https://github.com/civic-tech-pioneer/watane/releases/latest/download/install.sh | sh
```

To skip the Rust toolchain question:

```sh
curl -fsSL https://github.com/civic-tech-pioneer/watane/releases/latest/download/install.sh | sh -s -- --no-toolchain
```

See [installation behavior](install/FUNCTIONAL.md) for details.

Start at [spec/README.md](spec/README.md): the vision, the reading order,
and one row per subsystem.

| Folder | What it holds |
|---|---|
| `spec/` | The specification of the whole; `spec/design/` holds screen designs. |
| `pkg/`, `host/`, `dev/`, `app/`, `log/`, `dist/`, `net/`, `node/` | One subsystem each: `VISION.md`, `FUNCTIONAL.md`, `TECHNICAL.md`, `AGENTS.md`, then code. |
| `factory/` | How the code gets built: [README.md](factory/README.md) (the setup), [PLAN.md](factory/PLAN.md) (slices, done and next), `tasks/` (one brief per task). |
| `workspace-hack/` | Generated by `cargo hakari`; never edit by hand. |

```bash
cargo build && cargo test         # the whole workspace
```

Each subsystem's `AGENTS.md` lists its own commands and rules.
